# 1000道菜谱扩展包

2026-11-13。保留原341道的ID、变体及配方，新增659道，共1000道、1004个口味版本；荤菜471、素菜351、汤178。新增图片按用户本轮要求全部后续生成，659项列入image-jobs.json；本轮不生成、不借用其他菜的图片。

## 内容与重建

- base-bundle.json：当前341道的公开内容快照，不含账户/Key/个人资料。
- source-records.json：659份选定原记录，保留原配料、用量、步骤及图像链接；图像链接不用于产品展示。来源为[MIRecipe公开存档](https://github.com/bimissing/recipeData)，原站好豆。作者字段不明时署名来源平台及存档，不编造原作者。原来源未声明许可，不冒称取得许可；沿用项目D17-02公开配方准入决定。
- source-archives.json：公开下载URL、日期、字节数及SHA256。
- gallery-bundle.json / manifest.json：可校验的1000道完整发布载荷及摘要；保留原341道现有图片映射。
- image-jobs.json：659道后续AI配图任务，绑定recipeId、配料、步骤与目标文件名。

Node24通过tsx执行scripts/build-recipe-1000.ts可从版本化的base/source-records重新生成发布包，无网络或模型调用。初始选源脚本scripts/select-recipe-1000.py读取忽略目录.local-data/recipe-1000下的两个公开原档，按常见菜肴、完整流程、少配料优先筛选；排除饮料/主食/甜品/药膳标题，按菜名别名、主要原料+做法、步骤hash去重。不能将此工程筛选描述为独立人工审核、试做或营养/医学认证。

配料从原表及明确的做法文字提取，保留来源已给的用量；未知量不补造。多种调料连写仅在词汇完整覆盖时拆开，组合克重不分配到各项。新增营养为空，不把新食材自动映射为疾病证据。普通推荐仍按明列食品及调料执行限制，用户输入量不参与选菜。

## 本地使用

构建后执行Node24 --import tsx scripts/preview-recipe-1000.ts，访问http://127.0.0.1:15203/ 。此入口只有本地公开内容和普通推荐，无云连接、账户凭证或模型调用；游客收藏留本机。

已有研究预览可在后续授权重启时设置LOCAL_RECIPE_RELEASE=1000选择本包；默认仍是原341道。没有自行重启15199或更新线上内容。线上加载器响应上限由5MiB调整为12MiB，当前载荷约5.04MB；仍须校验发布hash、内容结构和撤回状态。真正上线仍须本地提交审核及发布授权。

验证入口：scripts/verify-recipe-1000.ts（公网拦截、手机桌面）；tests/recipe-1000.test.ts（逐方正常推荐、每项配料直接限制、旧ID/配方保持、来源字段与分页检查）。
