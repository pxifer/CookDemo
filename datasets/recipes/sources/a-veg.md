## 手撕包菜

<a id="r005"></a>

### 口味：椒香酸辣 · R005

**主料**

- 包菜1个

**辅料**

- 大蒜20克
- 青花椒、干辣椒适量

**调味料**

- 食用油适量
- 盐1.5克、味精1克、生抽3克
- 白糖、香醋少许

**做法**

1. 包菜剖开去硬芯，叶片撕成均匀小片；蒜切片。
2. 锅热加底油至七成热，下蒜、干椒、花椒炒香。
3. 加包菜大火炒至断生；原文约30秒，家用灶按实际调整。
4. 加盐、味精、糖，生抽沿锅边淋入，再加醋，大火迅速翻匀装盘。

来源：[美食作家王刚](https://m.xiachufang.com/recipe/103327266/)。

## 杂菜炒蛋

<a id="r007"></a>

### 口味：咸鲜 · R007

**主料**

- 鸡蛋4个
- 红薯粉条适量
- 豆芽适量
- 韭菜1小把
- 大红椒半个

**辅料**

- 原文没有另列辅料。

**调味料**

- 盐约1克另加蛋液少许
- 胡椒粉半勺、蚝油3克、老抽3克、生抽4克
- 糖、香醋少许，植物油适量

**做法**

1. 粉条用温水浸泡约30分钟，韭菜切段、红椒切丝，鸡蛋打匀并加少许盐。
2. 热油先将豆芽炒至断生盛出。
3. 另润锅留底油，蛋液煎约3分钟，中途翻面，煎香后铲碎。
4. 加入韭菜、椒丝、豆芽与泡好的粉条炒至成熟。
5. 加盐、胡椒、糖、蚝油、老抽调味，沿锅边淋生抽，临出锅加少许香醋炒匀。

来源：[美食作家王刚](https://m.xiachufang.com/recipe/104099005/)。

## 炝炒绿豆芽

<a id="r008"></a>

### 口味：炝香微辣 · R008

**主料**

- 绿豆芽400克

**辅料**

- 蒜数颗、姜1小块、小葱头数根
- 青花椒数颗、干辣椒10克

**调味料**

- 猪油20克
- 盐1.5克、白醋1克
- 白糖少许、水淀粉适量

**做法**

1. 豆芽洗净充分沥水；姜蒜葱切末、干椒剪小段。
2. 把盐、糖、白醋与水淀粉混成碗汁。
3. 热锅化猪油，下料头以小火炒香，干椒刚变色时加入豆芽。
4. 转大火炒至断生，倒入拌匀的碗汁，迅速炒匀、熟后出锅。

来源：[美食作家王刚](https://m.xiachufang.com/recipe/103334420/)。 含猪油；本站蔬菜分类不等于纯素。

## 蒜蓉蒸丝瓜

<a id="r012"></a>

### 口味：蒜香 · R012

**主料**

- 丝瓜适量

**辅料**

- 大蒜适量
- 红椒碎适量

**调味料**

- 食用油、盐、糖、鸡精、香油、蒸鱼豉油适量

**做法**

1. 将蒜剁蓉，约三分之二以少油小火炸金黄，倒入剩余生蒜蓉中，离火用盐、糖、鸡精调匀。
2. 丝瓜切厚块，挖浅凹，将金银蒜填入，排入蒸盘。
3. 水开后大火蒸约5分钟，至丝瓜熟软。
4. 撒红椒碎，另将香油烧热淋入，再加蒸鱼豉油调味。

来源：[央视《天天饮食》](https://tv.cctv.com/v/v3/VIDE1412833934435429.html)。

## 响油娃娃菜

<a id="r013"></a>

### 口味：麻辣蒜香 · R013

**主料**

- 娃娃菜适量

**辅料**

- 葱姜丝、蒜蓉适量

**调味料**

- 干辣椒、花椒、白芝麻适量
- 酱油、米醋、盐、糖、葱姜水、水淀粉、食用油适量

**做法**

1. 干椒与花椒分别以小火焙香，摊凉碾碎；娃娃菜去根撕条，入沸水焯熟。
2. 底油炒香葱姜丝，烹酱油，下娃娃菜炒去水汽。
3. 加盐、糖、米醋、葱姜水及部分椒碎，再添少量清水烧匀，用水淀粉勾汁装盘。
4. 在菜中间放蒜蓉，上铺芝麻及剩余椒碎，烧热油浇香。

来源：[央视《天天饮食》](https://tv.cctv.com/2015/08/11/VIDE1439259241950466.shtml)。

## 菌油粉丝蒸丝瓜

<a id="r022"></a>

### 口味：菌香蒜蓉 · R022

**主料**

- 丝瓜、杏鲍菇、茶树菇、粉丝各适量

**辅料**

- 蒜、香葱适量

**调味料**

- 食用油、盐、糖、蒸鱼豉油适量

**做法**

1. 菌菇切丝，以少量热油炸到金黄，菌丝和菌油分别保留；粉丝泡软。
2. 蒜剁蓉，一半以温油炸成金蒜，再与生蒜蓉、盐、糖混匀。
3. 丝瓜去皮切段，以淡盐水略泡；粉丝铺盘底，码丝瓜，铺金银蒜与菌丝。
4. 入蒸锅蒸约6—7分钟至熟，淋蒸鱼豉油、撒葱，烧热菌油浇在葱上。

来源：[央视《天天饮食》](https://tv.cctv.com/2015/07/06/VIDE1436147470205773.shtml)。

## 豆角烧茄子

<a id="r046"></a>

### 口味：紫苏豆豉 · R046

**主料**

- 豇豆、长茄子各适量

**辅料**

- 紫苏、葱、姜、蒜适量

**调味料**

- 盐、食用油、干辣椒、豆豉、蚝油、酱油、鸡精、糖适量

**做法**

1. 豇豆切段，茄子切条用盐抓匀；紫苏切碎，葱姜蒜切好。
2. 水加盐及少量油烧开，豇豆焯至熟后捞出过凉。
3. 少油煸茄子至熟软，下豇豆炒匀后一起盛出。
4. 另锅少油炒香干椒、豆豉和葱姜蒜，倒回茄子豇豆，加蚝油、酱油、鸡精、糖翻匀。
5. 撒紫苏叶，炒至入味即出锅。

来源：[央视网《天天饮食》](https://tv.cctv.com/2015/11/03/VIDE1446516602744509.shtml)。

## 蒜蓉蒸茄子

<a id="r047"></a>

### 口味：蒜香酱鲜 · R047

**主料**

- 长茄子适量

**辅料**

- 洋葱、蒜泥、红尖椒适量

**调味料**

- 食用油、酱油、盐适量

**做法**

1. 洋葱及红椒切碎，茄子去头切段码盘。
2. 锅中少量油炒香洋葱碎，盛出与蒜泥、酱油、盐和红椒碎拌成酱料。
3. 把酱料浇在茄子上，放入蒸锅蒸约20分钟至茄子熟软。

## 爆炒素鳝丝（香菇冬笋）

<a id="r052"></a>

### 口味：鸡油鲜香 · R052

**主料**

- 干香菇、冬笋各适量

**辅料**

- 鸡油、葱、姜、香菜梗适量

**调味料**

- 干淀粉、干辣椒、酱油、糖、盐、料酒、香油、食用油、清水适量

**做法**

1. 干香菇泡发，用少量淀粉揉洗后冲净；冬笋切丝焯水，鸡油切丁焯一下。
2. 鸡油另加少量清水、葱姜碎，小火熬化，滤去渣子。
3. 锅内加水、少量酱油、盐、糖、鸡油和葱姜末，香菇煮约5分钟入味后切丝。
4. 热锅凉油炒葱姜丝、干椒丝、香菇丝及笋丝，加入盐、糖、酱油、料酒，大火炒匀。
5. 放香菜梗并淋香油出锅。

来源：[央视网《天天饮食》](https://tv.cctv.com/2015/12/28/VIDE1451243519212551.shtml)。 主料是香菇与冬笋，列蔬菜类；实际使用鸡油，不能用于纯素条件。

## 糖醋脆皮豆腐

<a id="r053"></a>

### 口味：菠萝糖醋 · R053

**主料**

- 内酯豆腐、菠萝各适量

**辅料**

- 葱、姜适量

**调味料**

- 盐、淀粉、食用油、番茄酱、糖、白醋、清水适量

## 番茄炒蛋

<a id="r055"></a>

### 口味：酸甜 · R055

**主料**

- 番茄、鸡蛋各适量

**辅料**

- 原文没有另列辅料。

**调味料**

- 盐、糖适量
- 炒制用油：原页未注明用量

**做法**

1. 选充分成熟的番茄，洗净后切块；鸡蛋打入碗中，加盐搅打均匀。
2. 锅中放油烧热，倒入蛋液炒至凝固，盛出备用。
3. 锅中放入番茄翻炒至变软、析出汤汁，再倒回鸡蛋翻炒均匀。
4. 加入糖调成酸甜口味，炒匀后装盘。

## 凉拌长豆角

<a id="r070"></a>

### 口味：蒜辣醋香 · R070

**主料**

- 长豆角300克

**辅料**

- 小米辣20克、蒜15克、大葱1根

**调味料**

- 焯煮用盐约2克、食用小苏打约1克
- 拌汁用盐约1.2克、味精1克、蚝油3克、生抽2克、辣鲜露2克、葱油3克
- 糖、香醋、清水、凉开水适量

**做法**

1. 豆角去头尾切段，水烧开加焯煮用盐和小苏打。
2. 豆角中火煮至少约4分钟并确认完全熟透，捞入凉开水降温后沥水。
3. 小米辣切碎、蒜剁末、大葱切薄片。
4. 把拌汁的盐、味精、糖、蚝油、生抽、辣鲜露、香醋及葱油调匀。
5. 熟豆角与辅料、碗汁拌匀装盘。

来源：[美食作家王刚](https://m.xiachufang.com/recipe/103406985/)。 蚝油及辣鲜露保留在完整配料中，不能按清水煮豆角理解成分。
