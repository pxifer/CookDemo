## 玉米莲藕排骨汤

<a id="r009"></a>

### 口味：清鲜 · R009

**主料**

- 排骨800克
- 玉米1条
- 莲藕1节
- 胡萝卜2条

**辅料**

- 马蹄适量
- 大葱1根
- 生姜1块

**调味料**

- 料酒、食用油、盐、胡椒粉、水适量
- 白醋数滴

**做法**

1. 排骨与玉米切块，莲藕、胡萝卜切滚刀块，马蹄去皮，葱切段、姜拍开。
2. 排骨冷水入锅，加料酒烧开，撇沫后捞出清洗。
3. 润锅留底油，中小火将排骨与葱姜炒香约1分钟。
4. 加水与备好的玉米、莲藕、胡萝卜、马蹄，大火烧开并撇沫，滴醋。
5. 转小火炖约40分钟，或按原文用高压锅约15分钟；熟软后用盐、胡椒调味。

来源：[美食作家王刚](https://m.xiachufang.com/recipe/103344578/)。

## 冬瓜薏米丸子汤

<a id="r021"></a>

### 口味：清鲜 · R021

**主料**

- 肉馅、冬瓜、薏苡仁各适量

**辅料**

- 马蹄、葱姜、香菜适量

**调味料**

- 盐、料酒、胡椒粉、生粉、清水适量

**做法**

1. 薏米温水泡发；葱姜、料酒和水泡成葱姜水；冬瓜去瓤切块，入水煮。
2. 肉馅拌盐、料酒、葱姜水、胡椒、马蹄碎和生粉，摔打上劲。
3. 泡过的薏米先小火焙干至微黄，再下冬瓜汤中煮熟。
4. 把肉馅挤成丸子，小火下入汤中煮透。
5. 汤碗放胡椒和盐，盛入汤与丸子，撒香菜。

来源：[央视《天天饮食》](https://tv.cctv.com/2015/07/10/VIDE1436499727358518.shtml)。

## 白菜豆腐汤

<a id="r039"></a>

### 口味：清鲜 · R039

**主料**

- 白菜、豆腐各适量

**辅料**

- 姜适量

**调味料**

- 盐、鸡精、白胡椒粉、香油、开水适量

**做法**

1. 姜切丝，豆腐和白菜切成小块。
2. 锅中倒入开水，放姜丝、豆腐及白菜，以盐、鸡精和白胡椒粉调味。
3. 小火煮开，煮至白菜与豆腐成熟，出锅前淋香油。

来源：[央视网《天天饮食》](https://tv.cctv.com/2015/12/10/VIDE1449724801125709.shtml)。

## 银丝豆腐羹

<a id="r040"></a>

### 口味：咸鲜 · R040

**主料**

- 嫩豆腐、蛋清各适量

**辅料**

- 葱花适量

**调味料**

- 盐、胡椒粉、鸡精、水淀粉、开水适量

**做法**

1. 嫩豆腐切细丝，蛋清搅散。
2. 豆腐丝放入开水煮开，加盐、胡椒粉及鸡精，轻搅拌匀。
3. 淋水淀粉勾薄芡，再均匀倒入蛋清。
4. 煮开至蛋清凝结，装碗后撒葱花。

来源：[央视网《天天饮食》](https://tv.cctv.com/2015/12/02/VIDE1449018368565440.shtml)。

## 紫菜萝卜汤

<a id="r041"></a>

### 口味：陈皮清香 · R041

**主料**

- 白萝卜、紫菜各适量

**辅料**

- 陈皮适量

**调味料**

- 盐、鸡精、香油、开水适量

**做法**

1. 白萝卜洗净、去皮，切成细丝备用。
2. 锅中水烧开后放入陈皮，转小火煮至再次沸腾。
3. 放入萝卜丝，加入盐和鸡精；再次煮开后转小火，煮约6分钟至萝卜熟。
4. 放入紫菜，煮至紫菜散开；淋入香油，盛出即可。

来源：[央视网《天天饮食》](https://tv.cctv.com/2015/11/16/VIDE1447639201792363.shtml)。

## 金针海带汤

<a id="r042"></a>

### 口味：咸鲜 · R042

**主料**

- 金针菇、海带丝、胡萝卜各适量

**辅料**

- 香菜、小葱适量

**调味料**

- 食用油、十三香、盐、鸡精、清水适量

**做法**

1. 海带丝入沸水煮熟后捞出；胡萝卜切丝，金针菇去根分散，小葱和香菜切碎。
2. 热锅凉油炒香葱花，下胡萝卜丝、海带丝煸炒。
3. 倒清水，以十三香和盐调味，煮开后放金针菇。
4. 继续煮约3分钟至食材成熟，加鸡精，出锅撒香菜。

来源：[央视网《天天饮食》](https://tv.cctv.com/2015/05/26/VIDE1432604348693987.shtml)。

## 泡菜豆腐五花肉汤

<a id="r043"></a>

### 口味：韩式酸辣 · R043

**主料**

- 辣白菜泡菜、五花肉、豆腐各适量

**辅料**

- 洋葱适量

**调味料**

- 韩式辣椒酱1勺、热水适量

**做法**

1. 五花肉切片，洋葱切开，豆腐切块。
2. 五花肉入锅煎出油，下洋葱和辣白菜翻炒。
3. 加1勺韩式辣椒酱，冲热水，再放豆腐，小火慢炖。
4. 煮至汤汁稍浓、猪肉与配菜充分成熟后盛出。

来源：[央视网《天天饮食》](https://tv.cctv.com/2015/08/10/VIDE1439171641937135.shtml)。

## 农家萝卜丝羊肉汤

<a id="r045"></a>

### 口味：香料咸鲜配辣子 · R045

**主料**

- 羊肉、白萝卜各适量

**辅料**

- 黄花菜、木耳、香菜、葱、姜适量

**调味料**

- 干辣椒、八角、桂皮、花椒、香叶、小茴香适量
- 料酒、盐、白胡椒粉、食用油、辣椒面、清水适量

**做法**

1. 白萝卜切丝；羊肉切块，冷水下锅加葱姜和料酒焯煮，撇沫沥出。
2. 换开水，加羊肉、干辣椒、八角、桂皮、花椒、葱姜、香叶和小茴香，大火开后小火煮约30分钟至羊肉熟，中途撇出羊油留用。
3. 另锅用底油炒萝卜丝，再放黄花菜、木耳并烹料酒。
4. 倒入羊肉与原汤，以盐、白胡椒粉调味，煮至配菜熟软，盛入预热砂锅撒香菜。
5. 留出的羊油与等量食用油一起烧热，浇辣椒面制成辣子，随汤另上。

来源：[央视网《天天饮食》](https://tv.cctv.com/2015/12/23/VIDE1450825578365823.shtml)。
