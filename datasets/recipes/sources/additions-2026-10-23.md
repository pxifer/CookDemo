本轮分批新增12道此前目录没有的菜。按“类别 → 菜名 → 口味 → 食材 → 做法”整理，均只作内部研究，未写入候选数据库或正式内容表。原方未给用量的保持未知；未填写营养、份数及耗时。较权威指节目或采访出处可核，不表示本项目已试做、取得全文复用许可或通过专业审核。R411～R418供独立社区候选补批使用，不在本索引内。

## 荤菜

<a id="r401"></a>
### R401 酱爆鸡丁 · 酱香咸甜

- 来源：[央视《天天饮食》酱爆鸡丁](https://tv.cctv.com/2015/03/27/VIDE1427420641955841.shtml)。较权威来源；本轮早先已读取原页，后续复访失败，正式准入前再次核对。
- 主料：鸡胸肉。辅料：冬笋。
- 调料：黄酱、白糖、葱姜水、料酒、水淀粉、食用油、盐、老抽、香油，均未定量。
- 做法：
  1. 鸡肉改丁，用料酒、葱姜水、水淀粉和油拌匀上浆。
  2. 冬笋切丁，在加少量糖的水中焯过。
  3. 鸡丁滑油后捞出沥油。
  4. 留少量底油炒黄酱，放料酒、葱姜水、盐、老抽及糖，炒成棕红色酱汁。
  5. 下鸡丁和笋丁，旺火炒匀，点香油装盘。

<a id="r404"></a>
### R404 麻辣仔鸡 · 麻辣

- 来源：[华声在线采访玉楼东行政总厨黄建国](https://hunan.voc.com.cn/news/202602/31500869.html)。较权威来源；厨师职务依据该采访，不把新闻采访当作项目审核。
- 主料：嫩仔鸡1只。辅料：红椒、大蒜叶。
- 调料：植物油、盐、味精、酱油、白醋、花椒油、湿淀粉、干淀粉；蛋黄1个，其余用量未给。
- 做法：
  1. 鸡处理干净，去骨切丁；加入盐、味精、酱油、干淀粉和蛋黄拌匀。
  2. 切好红椒及蒜叶；另用味精、酱油、白醋、花椒油和湿淀粉调汁。
  3. 鸡丁先炸再沥油，升高油温后复炸，取出沥干。
  4. 锅中留底油炒红椒和蒜叶，回入鸡丁，倒入调汁炒匀出锅。
- 待核：新闻叙述与编号步骤对首炸熟度表述不同；家用操作参数、定量与实做仍未核验。保留完整流程研究，不作为可直接执行的正式配方。

<a id="r419"></a>
### R419 葱烤河鲫鱼 · 葱香酱甜（荤菜）

- 来源：[央视《回家吃饭》原页](https://tv.cctv.com/2016/03/29/VIDEmbwEMrg3becXWanCjCuj160329.shtml)，正文明确为特级厨师王磊制作。较权威出处；正文已读。
- 主料：较小的鲫鱼。辅料：大量小葱、姜、苦苣、金桔。调料：料酒、老抽、生抽、淀粉、胡椒粉、白糖、盐、花生油、水；均未定量。
- 做法：
  1. 小葱改长段，鱼吸干表面水分并扎浅孔。
  2. 油锅放姜片和盐，煎鱼后盛出。
  3. 原锅煎葱段，暂不翻动；将鱼放回葱上。
  4. 加两种酱油、料酒、水、胡椒粉和糖，烧约10分钟。
  5. 淋少量水淀粉及花生油，翻鱼，旺火收汁。
  6. 装盘，以苦苣和金桔点缀。
- 待核：10分钟是来源烹调参考，整鱼大小、定量及熟度未统一，不当成固定总耗时；未取得内容复用许可。

<a id="r420"></a>
### R420 糟溜鱼片 · 糟香咸鲜（荤菜）

- 来源：[央视《天天饮食》原页](https://discovery.cctv.com/20071121/101305.shtml)，较权威栏目出处；正文已读，未据此猜个人作者。
- 主料：草鱼。辅料：木耳、蛋清、姜。调料：盐、味精、白糖、香糟、淀粉、油、水；香糟另用酒糟、黄酒、桂花、盐和糖，均未定量。
- 做法：
  1. 酒糟拌黄酒、桂花、盐和糖，装纱布袋悬挂取滤液，作为原方香糟。
  2. 草鱼去骨改片，拌蛋清、盐和淀粉上浆。
  3. 鱼片过油至变色后捞出；木耳另焯熟。
  4. 锅中放少量水、鱼片、盐、味精、糖、姜水及香糟。
  5. 加水淀粉收成薄芡，炒匀，与木耳同盘盛出。
- 待核：原页未交代木耳泡发、香糟处理时长和家用油温，过油变色不能替代熟度核验；仅保存来源流程研究，未取得复用许可。

<a id="r402"></a>
### R402 毛豆丝瓜 · 咸鲜

- 来源：[央视《天天饮食》毛豆丝瓜／煎泡蛋汤](https://tv.cctv.com/2015/09/07/VIDE1441591925186133.shtml)。较权威来源。
- 主料：毛豆仁、丝瓜、油条。调料：葱、姜、盐、糖、黄酒、油；用量均未知，黄酒及油由步骤补入清单。
- 做法：
  1. 毛豆煮熟；丝瓜去皮切条，浸淡盐水；油条切小块。
  2. 将油条煸脆盛出。
  3. 葱姜炝锅，下丝瓜和毛豆炒熟，以盐、糖及黄酒调味，拌入油条即成。

### R403 煎泡蛋汤 · 咸鲜

- 来源同上；较权威来源。
- 主料：鸡蛋、西红柿。辅料：香葱、姜。调料：盐、水淀粉、食用油、开水、白胡椒、香油，均未定量。
- 做法：
  1. 番茄烫后去皮切粒；蛋液拌葱花、盐和水淀粉。
  2. 热油煎成蛋饼，加入姜末及番茄炒香。
  3. 冲开水煮开，用白胡椒、盐及香油调味。

### R405 广式盐焗虾 · 盐焗咸香

- 来源：[央视《天天饮食》广式盐焗虾](https://tv.cctv.com/2015/12/01/VIDE1448935801392933.shtml)。较权威来源；网页抓取器失败后，浏览器已读到完整正文。
- 主料：海白虾，用量未知。
- 调料：盐焗粉35g、粘米粉60g、鸡粉20g、沙姜粉3g、胡椒粉1g；另需炸制用油。上述克重是一批混合粉的比例，不是已经核定的单盘投料量。
- 做法：
  1. 虾洗净剪须，腹部改刀，清除虾线等，吸干水分。
  2. 将五种粉混合均匀，虾肉蘸上粉料。
  3. 原页用七成热油初炸至定型变色，捞出；升温后复炸约10秒，沥油装盘。油温的家用参数仍待实做核定。

<a id="r406"></a>
### R406 蒜香鸡翅 · 蒜香微辣

- 来源：[央视《天天饮食》蒜香鸡翅](https://tv.cctv.com/2015/10/27/VIDE1445909767176362.shtml)。较权威来源；以正文的“金蒜”为准，简介中的“全蒜／打算”是误字。
- 主料：鸡翅中。辅料：花生、白芝麻、洋葱、西芹、柠檬、香菜、姜。
- 调料：大蒜、盐、白酒、麻辣鲜、糖粉、炸蒜用油，均未定量；复合调料成分及辣度未核。
- 做法：
  1. 鸡翅内侧划刀，拌入西芹、洋葱、姜、香菜、大蒜、柠檬、盐和白酒，腌约10分钟。花生压碎，另备蒜蓉。
  2. 蒜蓉入温油炸成金黄，沥油。
  3. 翅皮朝下煎，定型后翻面，小火煎熟至各面焦黄，盛出。
  4. 焙香白芝麻，放花生碎及鸡翅，拌金蒜、麻辣鲜和少量糖粉。

### R407 豆角烧茄子 · 豉香

- 来源：[央视《天天饮食》豆角烧茄子](https://tv.cctv.com/2015/11/03/VIDE1446516602744509.shtml)。较权威来源。
- 主料：豇豆、长茄子。辅料：紫苏、葱、姜、蒜。
- 调料：盐、油、干辣椒、豆豉、蚝油、酱油、鸡精、白糖，均未定量；不作严格素食承诺。
- 做法：
  1. 豇豆切段；茄子切条加少量盐拌匀；紫苏及葱姜蒜切好。豇豆入加盐和油的水焯后过凉。
  2. 煸软煸熟茄条，加入豇豆炒制，盛出。
  3. 炒香干辣椒、豆豉及葱姜蒜，回入两种主料，以蚝油、酱油、鸡精和糖调味，最后拌紫苏出锅。

<a id="r408"></a>
### R408 凉拌千张 · 醋香咸鲜

- 来源：[央视《天天饮食》凉拌千张](https://tv.cctv.com/2015/07/10/VIDE1436494088608424.shtml)。较权威来源；浏览器已读正文。
- 主料：千张。辅料：胡萝卜、香菜。调料：盐、白糖、米醋、芝麻油，均未定量。
- 做法：
  1. 千张和胡萝卜分别切丝，焯过后放凉。
  2. 调匀盐、糖、米醋及芝麻油，拌入两种丝，撒香菜末即成。

<a id="r409"></a>
### R409 干锅素什锦 · 干锅酱香

- 来源：[央视《天天饮食》干锅素什锦](https://tv.cctv.com/2015/11/26/VIDE1448505726391673.shtml)。较权威来源；浏览器已读正文。
- 主料：口蘑、莲藕、青笋、红薯、香芹。辅料：木耳、姜、蒜。
- 调料：油、豆豉、干锅酱、生抽、白糖、盐、鸡精、十三香，均未定量。干锅酱及鸡精的成分、辣度未知，不据菜名推断严格素食或过敏适用。
- 做法：
  1. 青笋、红薯、香芹、藕切条，口蘑切片；木耳焯熟。
  2. 小火煸香豆豉和蒜碎，盛出。
  3. 依次煎熟红薯、藕、口蘑和青笋，沥油。
  4. 以姜、干锅酱及前述豆豉蒜碎炝锅，加入全部食材，用生抽、糖、盐、鸡精和十三香炒匀，盛入热砂煲。

## 汤品：第二批

<a id="r410"></a>
### R410 冬瓜丸子汤 · 咸鲜

- 来源：[央视《天天饮食》冬瓜丸子汤](https://tv.cctv.com/2015/07/10/VIDE1436499727358518.shtml)。较权威来源；不保留原页的功效宣传。
- 主料：冬瓜、肉馅（原页未定肉种）。辅料：薏苡仁、马蹄、葱、姜、香菜。
- 调料：盐、料酒、胡椒粉、生粉、水，均未定量。
- 做法：
  1. 薏苡仁温水泡发；葱姜、料酒和水调成葱姜水。冬瓜去瓤留皮切块，入水煮制。
  2. 肉馅拌盐、料酒、葱姜水、胡椒、马蹄碎和生粉，搅拌摔打成馅。
  3. 泡过的薏苡仁小火焙至微黄，放入冬瓜汤继续煮。
  4. 挤入丸子，小火煮熟，以盐和胡椒调味，盛碗撒香菜。丸子大小、熟制时间及肉种仍需量化核方，不能据此直接缩放或判断过敏。
