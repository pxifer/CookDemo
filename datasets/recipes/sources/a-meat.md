## 牛肉末麻婆豆腐

<a id="r001"></a>

### 口味：麻辣 · R001

**主料**

- 老豆腐400克
- 牛肉50克

**辅料**

- 泡姜15克
- 泡椒20克
- 蒜苗1根

**调味料**

- 干辣椒10克、青花椒5克（制刀口辣椒）
- 豆豉、豆瓣酱、菜籽油、水淀粉各适量
- 猪油10克、味精1克、老抽1克
- 盐、糖、清水、明油适量

**做法**

1. 豆腐改小方块，牛肉剁碎，泡姜泡椒及蒜苗切细。
2. 辣椒与花椒少油小火炒至浅褐，晾后剁成刀口辣椒；豆腐入加盐的水中汆约1分钟沥出。
3. 润锅后用菜籽油及猪油炒干牛肉末，下豆瓣、泡姜泡椒与豆豉炒香，再下约5克刀口辣椒。
4. 加水烧开，以盐、味精、糖、老抽调味，下豆腐小火烧入味；原文家用小灶约5分钟。
5. 水淀粉分三次勾入，后两次离火，芡由稀到浓；淋明油装盘，撒刀口辣椒和蒜苗。

来源：[美食作家王刚](https://m.xiachufang.com/recipe/103303387/)。 含牛肉与猪油，归荤菜。

## 宫保鸡丁

<a id="r002"></a>

### 口味：糊辣荔枝味 · R002

**主料**

- 带骨鸡腿约500克
- 油酥花生米30克

**辅料**

- 姜10克
- 蒜2颗
- 香葱1小把
- 干辣椒5克、青花椒适量

**调味料**

- 腌料：盐0.5克、料酒5克、老抽1克、干淀粉3克、胡椒粉及油少许
- 碗汁：料酒15克、生抽5克、香醋2克、糖5克、味精1克、淀粉1勺、老抽及胡椒少许
- 滑油约750克（锅中用油）、底油与明油少许

**做法**

1. 鸡腿去骨切丁，依次拌腌料，最后拌油，放置约5分钟。
2. 姜蒜切粒、葱切段，干椒剪段；将碗汁混合。
3. 热锅加滑油后离火，下鸡丁滑散至八成熟，倒出沥油。
4. 留底油炒香干椒花椒和姜蒜，鸡丁回锅大火翻匀。
5. 碗汁再次搅匀后倒入，炒到汁紧、鸡肉熟透，再加花生与葱段，淋明油出锅。

来源：[美食作家王刚](https://m.xiachufang.com/recipe/103465343/)。 滑油量不是食用摄入量。

## 鱼香肉丝（木耳笋丝版）

<a id="r003"></a>

### 口味：鱼香 · R003

**主料**

- 猪里脊200克
- 黑木耳40克
- 罗汉笋3根

**辅料**

- 小葱30克
- 红泡椒30克
- 蒜20克
- 姜20克

**调味料**

- 腌料：盐0.5克、料酒5克、生抽3克、蛋清半个、胡椒及淀粉适量
- 碗汁：盐0.5克、味精1克、糖10克、料酒8克、生抽5克、陈醋8克、干淀粉2克
- 焯料盐约2克；植物油适量

**做法**

1. 里脊切丝后洗去血水、挤干，拌腌料搅匀上浆；配菜切丝、泡椒姜蒜剁细。
2. 木耳和笋用加盐开水汆至断生沥出；碗汁调匀。
3. 润锅加油至四成热，肉丝滑白后捞出控油。
4. 底油以中小火炒香姜蒜泡椒，加入肉丝、木耳和笋翻匀。
5. 碗汁搅匀倒入，大火收紧，加入葱段炒匀出锅。

来源：[美食作家王刚](https://m.xiachufang.com/recipe/103300358/)。

## 虾仁滑蛋

<a id="r004"></a>

### 口味：咸鲜 · R004

**主料**

- 鲜虾80克（去壳前）
- 鸡蛋5个

**辅料**

- 葱花适量

**调味料**

- 盐1.5克
- 胡椒粉适量
- 白醋少许
- 食用油适量

**做法**

1. 虾挑去虾线，入沸水煮熟后剥壳去头，虾仁片开。
2. 鸡蛋与虾仁合碗，加盐、胡椒、醋和葱花，朝同向拌匀。
3. 热油润锅并倒出，再放少量底油，倒入蛋液。
4. 先借锅的余热推至初步定形，再用小火推滑至蛋液凝固、虾蛋均熟，装盘。

来源：[美食作家王刚](https://m.xiachufang.com/recipe/103304387/)。

**调味料**

- 白糖、生抽、老抽、料酒、香油、米醋、食用油适量

**做法**

## 枣生栗子鸡

<a id="r011"></a>

### 口味：咸甜 · R011

**主料**

- 鸡腿肉、花生、栗子、红枣各适量

**辅料**

- 葱、姜、蒜适量

**调味料**

- 胡椒粉、料酒、姜汁、盐、淀粉、生抽、绵白糖、水淀粉、油、水适量

**做法**

1. 姜丝用热水泡成姜汁，鸡腿切块，以胡椒、料酒、姜汁、盐抓匀，再拌淀粉。
2. 少油将鸡腿煸到八成熟盛出，另用少油与绵白糖炒糖色。
3. 鸡肉及葱姜蒜入锅炒匀，再添料酒、姜汁、开水，加入花生、栗子和红枣。
4. 用生抽、糖、盐调味，烧至鸡肉与配料成熟入味，以水淀粉收汁装盘。

## 干贝扒冬瓜

<a id="r015"></a>

### 口味：海鲜咸鲜 · R015

**主料**

- 冬瓜、干贝各适量

**辅料**

- 葱姜末适量

**调味料**

- 葱油、料酒、干淀粉、盐、鸡精、白胡椒、老抽、香油、油、水适量

**做法**

1. 干贝去硬肌，加热水蒸约1小时，留汁并搓成丝；冬瓜去皮切薄片。
2. 冬瓜先低温油浸至透明，再入沸水焯熟沥出。
3. 底油爆葱姜，烹料酒，下冬瓜和开水，以鸡精、盐、胡椒、老抽调味，加部分干贝原汁小火煨。
4. 盛出少许汤汁给干贝，冬瓜勾芡、淋香油入盘。
5. 锅中加入干贝、原汁及老抽，煮匀勾芡，浇在冬瓜上。

来源：[央视《天天饮食》](https://tv.cctv.com/2015/08/06/VIDE1438826403191363.shtml)。

## 榨菜蒸牛肉

<a id="r016"></a>

### 口味：榨菜咸鲜 · R016

**主料**

- 牛里脊、榨菜头各适量

**辅料**

- 芹菜、姜、蒜适量

**调味料**

- 蚝油、蛋清、生抽、糖、生粉、色拉油、清水适量

**做法**

1. 榨菜切大片，以清水泡约10分钟，清理并挤干。
2. 牛里脊去筋切大片，以生抽、糖、蚝油、蛋清、水、生粉抓匀上浆，再拌油、蒜蓉和姜片。
3. 牛肉与榨菜拌匀，薄薄平铺在蒸盘中。
4. 大火蒸约6分钟，倒出多余汁液，撒芹菜碎再蒸约1分钟至牛肉熟透。

## 酸汤肥牛

<a id="r017"></a>

### 口味：酸辣 · R017

**主料**

- 肥牛片、水晶粉各适量

**辅料**

- 金针菇、西红柿、大葱、蒜适量

**调味料**

- 黄椒酱、醪糟、柠檬、盐、少许油、热水适量

**做法**

1. 水晶粉温水泡软，番茄切丁、葱切段。
2. 锅中用水及少许油煮炒葱、番茄，汁浓后下蒜末、黄椒酱，冲热水。
3. 煮开加醪糟，再开锅后滤去碎渣，加入金针菇和粉煮熟，以盐调味，捞出垫底。
4. 小火将肥牛片滑入汤中养至成熟，捞出码盘，挤入柠檬汁。
5. 汤再次煮开撇沫，浇到肥牛及配菜上，撒蒜末。

## 蒜香排骨

<a id="r018"></a>

### 口味：蒜香 · R018

**主料**

- 排骨、土豆、芋头各适量

**辅料**

- 大蒜适量

**调味料**

- 小苏打、盐、糖、十三香、蒜粉、生粉、糯米粉、吉士粉、白芝麻、水、油适量

**做法**

1. 大蒜制汁；排骨用小苏打、盐和蒜汁抓洗，泡约20分钟后洗净，土豆、芋头切条。
2. 排骨以盐、糖、十三香、蒜粉、生粉、糯米粉、吉士粉及少量水拌匀挂浆。
3. 五成热油下排骨炸至挺实微黄并熟透，再下拌过吉士粉的土豆和芋头炸熟炸金黄。
4. 捞出沥油，回干净炒锅，加白芝麻、蒜粉及十三香混合料翻匀出锅。

来源：[央视《天天饮食》](https://tv.cctv.com/2015/07/20/VIDE1437357481239618.shtml)。 吉士粉实际产品成分另核；原文未给各粉定量。

## 五花肉小炒豆腐

<a id="r019"></a>

### 口味：酱香微辣 · R019

**主料**

- 北豆腐、五花肉各适量

**辅料**

- 青蒜、小米辣、姜适量

**调味料**

- 盐、料酒、葱姜水、黄酱、生抽、老抽、鸡精、十三香、食用油适量

**做法**

1. 豆腐切大片，拌盐、料酒和葱姜水略腌，用厨房纸吸干。

4. 加生抽、老抽、小米辣及豆腐，调入鸡精、十三香，再放青蒜大火炒至熟匀装盘。

## 剁椒香菇盒

## 沙姜清远鸡

<a id="r068"></a>

### 口味：沙姜豉香 · R068

**主料**

- 清远鸡1只（原页未给重量）

**辅料**

- 沙姜、圆葱、香葱、姜适量

**调味料**

- 料酒、盐、食用油、豉油、生抽、清水适量

**做法**

1. 整鸡清理干净，香葱打结，姜和部分沙姜切片。
2. 水烧开，放葱姜及沙姜，整鸡下锅烫紧表皮，加料酒、盐；来源加盖煮10分钟后关火浸15分钟。
3. 取鸡过凉，吸干表面水分，薄抹油后斩块码盘。
4. 圆葱与余下沙姜切小粒，热锅少油炒至出香变色，加豉油和生抽炒匀，作蘸汁同上。

## 椒麻杏鲍菇拌虾片

<a id="r069"></a>

### 口味：藤椒椒麻 · R069

**主料**

- 杏鲍菇、鲜虾各适量

**辅料**

- 香葱、鲜藤椒适量

**调味料**

- 鸡精、盐、料酒、橄榄油、食用油、淀粉、清水适量

**做法**

1. 水加鸡精、盐和料酒烧开，香葱焯后过凉；热油淋鲜藤椒，加香葱段、橄榄油打碎，过滤并调盐成椒麻汁。
2. 杏鲍菇横向剖开，沸水煮约20分钟，捞出切薄片。
3. 虾去壳去线，加盐、料酒和淀粉，捶成薄虾饼。
4. 来源用约80℃的水将虾片浸至熟，过凉后切小片。
5. 虾片与杏鲍菇拌合，淋椒麻汁拌匀。
