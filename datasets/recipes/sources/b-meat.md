## 罐焖牛肉

<a id="r028"></a>

### 口味：番茄咸鲜 · R028

**主料**

- 牛肋条、土豆、胡萝卜、西红柿、洋葱各适量

**辅料**

- 芹菜、葱、姜、香菜适量

**调味料**

- 黄油、食用油、番茄酱、香叶、八角、糖适量
- 盐：首次压牛肉3克，后续调汤适量
- 清水适量

**做法**

1. 牛肋条切约4厘米块，冷水焯煮并撇净浮沫，保留澄清原汤；蔬菜切块、葱姜切段片。
2. 底油炒香葱姜和牛肉，移入压力锅，加芹菜、洋葱、胡萝卜、香叶、八角、盐3克与原汤。
3. 按器具要求上汽后压约30分钟，正常泄压开盖，挑出葱姜、芹菜和香料，留牛肉及汤。
4. 另锅炒香香叶、八角、洋葱与西红柿，再下黄油、胡萝卜和番茄酱。
5. 加入牛肉、原汤、土豆、糖、盐和芹菜，移回压力锅，上汽后再压约3分钟并正常泄压。
6. 倒回炒锅，挑出香料，加香菜小火煮1—2分钟，再捞出香菜装盘。

来源：[待我去买个橘子｜注明转自B站隋坡](https://m.xiachufang.com/recipe/107825198/)。 来源未给整菜主料克重；保留原有计量边界。

## 东坡肘子（芸豆清炖版）

<a id="r029"></a>

### 口味：清鲜 · R029

**主料**

- 猪前肘1只
- 芸豆适量

**辅料**

- 姜、葱、白芷适量、花椒十余粒

**调味料**

- 高汤、清水、盐适量

**做法**

1. 芸豆用冷水泡一晚；肘子燎净毛，温水浸泡后刮洗，侧面开刀并在厚肉处划开。
2. 肘子冷水入锅，加花椒、姜葱，烧开撇沫，中火盖煮约半小时后取出。
3. 砂锅放肘子、泡好的芸豆、姜片、葱结、1粒花椒及几片白芷，加高汤并调盐。
4. 煮开后转小火炖约100分钟，至肘子软烂且芸豆充分熟透。

来源：[缘来遇见｜注明隋坡版并自行加白芷](https://m.xiachufang.com/recipe/107556940/)。 记录的是作者改动后的清炖版，不能当作红烧肘子或隋坡原方。

## 东安鸡

<a id="r030"></a>

### 口味：姜醋酸辣 · R030

**主料**

- 带皮鸡腿肉200克

**辅料**

- 姜、葱丝、三色彩椒条、辣椒适量
- 花椒20粒

**调味料**

- 黄酒、香油、味精、盐、湖南米醋、白胡椒粉、水淀粉适量

**做法**

1. 鸡腿肉冷水下锅，加姜片、花椒与黄酒煮至断生，切条并留鸡汤；姜葱和彩椒切丝。
2. 锅中用香油低温炒香辣椒及姜丝，留少量姜丝待后下。
3. 放鸡条，加鸡汤、黄酒、味精、盐及米醋，小火焖收，撒白胡椒粉。
4. 加入葱丝、余下姜丝和彩椒条，炒至鸡肉熟透、配菜成熟。
5. 转大火收汁，补少量米醋并勾薄芡，最后加香油及拍碎花椒出锅。

来源：[PUCKPUCK｜注明搬运老饭骨传统版](https://m.xiachufang.com/recipe/106625786/)。 网友转记，姜醋用量尚未定量。

## 红焖羊肉

<a id="r031"></a>

### 口味：香料酱辣 · R031

**主料**

- 羊腩750克
- 羊腿肉1000克
- 胡萝卜1—2根

**辅料**

- 葱1根、姜约3片、蒜约5瓣
- 枸杞约20粒、红枣约5颗

**调味料**

- 豆瓣酱约2勺、干辣椒约4个、香叶约3片
- 花椒、孜然、山奈、白胡椒粒、小茴香、白芷各5克，丁香约5粒
- 啤酒2罐、生抽1勺、鸡粉2勺、糖2勺、食用油及清水适量

**做法**

1. 羊肉洗净切大块，厚处切开；胡萝卜切块，葱姜蒜备好。
2. 油中小火炒豆瓣至出红油，下全部香料炒香，再下葱姜蒜。
3. 加入羊肉煸至收缩，倒啤酒，视情况补水至稍没羊肉，加生抽、鸡粉、糖烧开。
4. 转压力锅，加入胡萝卜、红枣与枸杞，上汽后约15分钟，关火焖约5分钟。
5. 按器具要求完成泄压再开盖，检查肉和配菜已熟软后盛出。

来源：[葱花少许｜注明整理自老饭骨](https://m.xiachufang.com/recipe/106913776/)。 网友记录的原量较大；整菜固定量保留，不按用餐人数缩放。

## 辣椒炒肉

<a id="r032"></a>

### 口味：豆豉椒香 · R032

**主料**

- 五花肉500克
- 螺丝青椒3—4个

**辅料**

- 蒜4瓣、姜3片、小米辣2个（可不加）

**调味料**

- 豆豉半勺、酱油1勺、老抽半勺
- 蚝油1勺、黄酒1勺、味精少许

**做法**

1. 五花肉切片，姜蒜小米辣切片，青椒切滚刀块，豆豉按来源先蒸一下。
2. 空锅烧热，干煸青椒至表面微焦，盛出。
3. 锅重新烧热，不另加油，煸肉片至出油、有焦香。
4. 下豆豉和小米辣炒匀，再放姜蒜、蚝油炒香，烹黄酒、酱油及老抽。
5. 加味精，把青椒倒回锅内，大火炒至肉和青椒熟透出锅。

来源：[葱花少许｜注明整理自老饭骨](https://m.xiachufang.com/recipe/106911348/)。

## 大盘鸡

<a id="r033"></a>

### 口味：豆瓣香辣 · R033

**主料**

- 鸡腿2只
- 黄心土豆4个
- 螺丝椒3个

**辅料**

- 葱、姜、蒜、干辣椒、花椒适量

**调味料**

- 盐：腌鸡3克，煮土豆及调汤另用适量
- 酱油、冰糖、花生油、豆瓣酱、白胡椒粉、花椒粉、十三香、玉米淀粉、黄酒、热水适量

**做法**

1. 鸡腿切块沥水，用盐3克、白胡椒粉、花椒粉、黄酒及淀粉抓腌；葱留两份，姜切片、蒜拍切，干椒泡软。
2. 土豆切大滚刀块，加盐及酱油煮熟沥出；螺丝椒去筋切块。
3. 花生油中把冰糖炒化，下鸡块炒至收缩，再加姜、一份葱、干椒、花椒、豆瓣酱、花椒粉、十三香。
4. 炒匀后加刚没鸡块的热水，用酱油、盐调味，煮至鸡肉熟透且汁稍稠。
5. 加入熟土豆煮至表面起沙、汤汁浓稠，再放剩余葱、蒜和螺丝椒，炒煮至椒熟后装盘。

来源：[土豆兔兔妞｜注明跟抖音老饭骨学习](https://m.xiachufang.com/recipe/104232976/)。 作者记录15份做过；只能证明有跟做记录，不能视为15份一致好评。

## 海南黄椒石斑鱼片

<a id="r035"></a>

### 口味：黄椒鲜辣 · R035

**主料**

- 石斑鱼肉约700克

**辅料**

- 黄椒1个、小米辣、葱花适量

**调味料**

- 海南黄灯笼椒酱5勺、蚝油2勺
- 盐、糖、米酒、淀粉、花生油、热油适量

**做法**

1. 鱼肉切片，用盐、蚝油、糖和米酒拌腌。
2. 黄椒切末，与黄椒酱、小米辣及淀粉水加入鱼片抓匀，最后用花生油封住。
3. 鱼片尽量单层平码在蒸盘中，水开后大火蒸约8—10分钟，检查鱼片已熟。
4. 撒葱花，淋热油后上桌。

来源：[Hannie厨房小白｜注明复刻农国栋](https://m.xiachufang.com/recipe/106683968/)。 作者反馈叠片影响口感；700克是步骤实际量，不是按原表“一条鱼”估算。

## 广式豉油鸡

<a id="r036"></a>

### 口味：豉油香料 · R036

**主料**

- 三黄鸡1只，约1000克

**辅料**

- 葱2根、姜4片、红葱头2个

**调味料**

- 海鲜豉油100克、老抽2调羹、冰糖20克、红糖20克
- 广东米酒70克、水500克
- 八角2个、花椒约10粒、桂皮约4厘米、香叶2片、草果2个、甘草约10粒
- 花生油、清洗用盐、生粉水适量

**做法**

1. 鸡清理内脏与多余脂肪，按来源用盐擦洗后冲净；香料干炒出香后装袋。
2. 花生油炒香葱姜和红葱头，依次倒米酒、豉油、老抽、两种糖，煮开后加水及香料袋。
3. 锅底垫可煮食的网格防粘，先用热汁反复淋鸡使表皮收紧，再把鸡放入。
4. 小火加盖，每约5分钟翻面并浇汁；来源约1000克鸡煮20分钟，实际须检查最厚处已熟透。
5. 取鸡并倒出腹内汤汁，稍放凉斩块；原汁捞去香料葱姜后浓缩，转小火用生粉水勾芡，淋在鸡上。

来源：[蛋花Danford｜参考农国栋并自行调整](https://m.xiachufang.com/recipe/104338274/)。 原表为红葱头，步骤写洋葱，葱头品种待核；不是农国栋酒店原方。

## 红烧鸡腿

<a id="r038"></a>

### 口味：酱香微甜 · R038

**主料**

- 鸡腿4个（作者跟做记录）

**辅料**

- 葱、姜、蒜、桂皮、八角、香叶适量

**调味料**

- 老抽1勺、生抽3勺、蚝油1勺、冰糖4颗
- 料酒、食用油、开水适量

**做法**

1. 鸡腿划刀，冷水下锅，加葱姜料酒焯去血沫，捞出洗净。

3. 加入老抽、生抽、蚝油和冰糖翻匀，倒开水至鸡腿高度约2/3。
4. 加入桂皮、八角、香叶，烧开转小火约20分钟，检查鸡腿熟透后大火翻动收汁。

## 青椒肉丝（二刀肉版）

<a id="r059"></a>

### 口味：椒香咸鲜 · R059

**主料**

- 二刀肉300克
- 青椒300克

**辅料**

- 嫩姜15克、蒜15克

**调味料**

- 盐2克（腌肉1克，炒制1克）、老抽1克、生抽3克、味精1克
- 食用油、糖、香醋适量
- 料酒、胡椒粉可选

**做法**

1. 肉切丝，青椒与嫩姜切丝，蒜切片。
2. 肉丝用盐1克、老抽1克拌匀，再拌油；来源允许自行选加料酒、胡椒粉，不加淀粉。
3. 热锅放油，约五成热下肉划散，中火炒香，再下姜蒜。
4. 放青椒大火炒至断生，加入余盐、味精、少量糖和醋，生抽沿锅边烹入。
5. 继续大火炒匀至肉和青椒成熟即出锅；来源两段快炒各约10秒，实际以成熟状态为准。

来源：[小鹿yoyo｜标题王刚版](https://m.xiachufang.com/recipe/103408523/)。 网友整理，不能作为王刚本人发布的原方。

## 蛤蜊焖鸡

<a id="r065"></a>

### 口味：海鲜酱鲜 · R065

**主料**

- 小公鸡、吐净沙的海蛤蜊各适量

**辅料**

- 葱、姜、蒜适量
- 鸡心、鸡肝、鸡胗适量

**调味料**

- 花生油、蚝油、味极鲜酱油、盐、糖、胡椒粉适量
- 啤酒半罐

**做法**

1. 鸡斩成大小均匀的块，葱姜蒜备好；蛤蜊提前吐净沙。
2. 锅先润油，再用花生油大火炒鸡，减少频繁翻动，炒干水分至表面微黄。
3. 放足葱姜蒜炒香，再下蚝油和酱油炒上色。
4. 加半罐啤酒、鸡杂、盐、糖和胡椒粉，加盖中小火烧约10分钟至鸡肉熟。
5. 转大火收紧汤汁，下蛤蜊加盖再焖约2分钟至蛤蜊成熟开口，翻匀装盘。

来源：[爷俩儿好菜｜抖音索引文稿](https://www.douyin.com/shipin/7642499809266075675)。 抖音聚合索引里的文稿，尚未逐段对照原视频及主料用量。

## 干锅花菜（五花肉版）

<a id="r066"></a>

### 口味：豆豉酱辣 · R066

**主料**

- 花菜、五花肉各适量

**辅料**

- 花椒、姜、蒜、葱白、青红椒、香葱、洋葱适量

**调味料**

- 豆瓣酱1勺、老干妈豆豉1勺、生抽半勺
- 糖、鸡精、食用油适量

**做法**

1. 五花肉切片，花菜分小朵，葱姜蒜切粒，洋葱切丝，青红椒及香葱切好。
2. 热锅凉油煸肉，下花椒，肉微黄后放葱姜蒜。
3. 加入豆瓣和豆豉，小火炒出红油，再下花菜转大火。
4. 加生抽、糖、鸡精快炒，放青红椒，花菜充分成熟后放香葱。
5. 另把砂锅加少量油与洋葱丝烧热，倒入炒好的花菜上桌。

来源：[CaCa需停止消极｜注明小红书爷俩儿好菜](https://www.xiachufang.com/recipe/107270943/)。 小红书原笔记未核；含五花肉，归荤菜。
