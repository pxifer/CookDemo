# 甲减、海藻与碘：说明型研究知识候选

本批由开放用例q03的用户反馈驱动：原回答只说未覆盖，用户给需求满足度2/4，希望补能否吃、频率、量和食材建议。不能因此编造个人海带克数。

- 3来源、6证据、4说明事实、2覆盖限制；[知识数据](knowledge.json)与[manifest](manifest.json)独立版本，旧v1/v2/v3知识、PG索引和目标包保持。
- 来源是NIH/NIDDK甲减与桥本页面，以及香港CFS 2025报告中的背景/公共建议句；不复制CFS研究测量、表格或图片，不声称已取得研究数据再利用许可。全文仅原缓存，短摘保留出处与原文hash。
- 使用现有锁定解析器，完整正文块或带父段回溯的完整句；保留DOM节点、规范文本offset、span/parent/source hash。数值型个人频率与份量为null，禁止把通用碘参考换成海带克数。
- 这是解释性知识，**没有新增可执行禁食/推荐规则、没有入PG或新增向量，不是临床签认**。由本地评测worker按原文理解出的疾病及所问食材检索，甲亢/贫血或无关食品不因近似词被当成同题。
- 回答明确桥本/自身免疫前提、孕期限定及一般食物来源与患者饮食处方的区别；过敏/忌口不能被一般食物来源说明绕过。

离线重建：`python scripts/build-thyroid-explanation.py --cache .local-data/evaluation/source-cache`。原件hash、解析依赖、正文唯一性或输出内容变化时拒绝覆盖，需新版本。NIH ODS原网页直取被访问保护阻断，未绕过或假装取得原HTML；本候选不使用其未落地内容。

相关主线见[输出评测闭环](../../../agent-design/docs/output-evaluation-2026-11-13.md)。推广新病种应由新来源与独立问题驱动，不能把本题的改进当成所有疾病都已覆盖。
