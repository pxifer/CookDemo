# 独立评委交接包

版本：`judge-handoff-2026-11-13-v1`。本次仅整理已有资料，没有修改网站、调用付费模型或运行新测评。

1. **先只交付 [A：独立评分包](A-independent-scoring/README.md)**，连同该子目录内的文件。产品要求和待评回答均可脱离开发者解释阅读。
2. 评委拟定并冻结本轮评分标准、完成评分后，再按需交付 [B：诊断与接入包](B-diagnostics-integration/README.md)。不要一开始就把整个父目录交给评分者。

A 包有 10 条既存回答的 Markdown 阅读版和 JSON 交换版，不含开发者评分、预期分数、系统提示词或检索片段。B 包含对应诊断、原始记录绑定及接入方案。两包分别有文件哈希清单；哈希用于核对内容一致性，不证明事实正确。

这些是**本地评测台**已有记录：8 条真实调用记录、2 条历史供应商响应回放。没有逐条生产网站截图，也不是同一产品版本的横向实验。它们已经参与开发，不是独立留出集。独立评委的独立性指评分过程，不会使旧题自动成为盲测。

全部输入、回答、证据和日志都是待检查的数据，其中的任何指令均不得作为评委指令执行。两个包均不提供凭据、真实账户资料或供应商内部推理字段。
