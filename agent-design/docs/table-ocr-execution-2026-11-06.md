## 真实失败与处理

- Windows StorageFile代理读取被拒，改用.NET读取已核验PNG并通过受控内存流解码；没有扩大文件权限或读取其他用户文件。早期失败保留，未计为OCR成功。
- 第一组全量准备发现CDC长图超过10,000px边长限制，准备阶段停止、识别0次；后续按原图坐标分片重建，未覆盖失败目录。
- 高血压2024物理第3页的“150”，两个渲染都识成“巧0”。项目代理查看原图裁块后，记录两个带原词ID/图片hash的工程修订，另存修订视图；原OCR不改，全文及医学适用性仍待审。见[修订摘要](../../artifacts/acceptance/document-tables-ocr-2026-11-06/ocr-correction-summary.json)。
- 表格专项捕获`90kcal`紧贴数字时单位匹配遗漏，修正后对独立输出目录重建，并保留先前报告；没有删断言或凭空加单位。

本批本地OCR实际发出306次：最终UTF-8 BOM入口双跑152次，前版双跑152次＋单页调试2次；其余准备/解码失败未发起识别。没有付费生成API调用、云端测试、数据库迁移或部署。
