# 食材指导与本餐推荐接入契约

日期：2026-11-04；2026-11-05按[真实界面复核](business-rag-example-2026-11-05.md)修订选菜与引用职责。执行 [TODO A1～A7](todo.md)；本阶段仅本地研究，不部署、不开放正式疾病规则。11月5日的1元界面授权独立于已关闭的旧脚本预算。

同日后续按 D19-13 忽略用户填写量：食材清单仅表示有无，保留过敏忌口、有效避开、调料与补买限制；参考量不影响候选、排序、菜数、累计缺额，不送模型选菜。菜谱原始量和营养保留。见[用量策略验收](../../docs/releases/ACCEPTANCE-quantity-policy-2026-11-05.md)。

## 输入与任务

- 复用服务端当前账户的 `healthProfile.conditions/goals/notes`、按主题接受记录，以及本餐库存、调料、过敏忌口、补买、口味、人数和真实目录；不信任客户端替换账户档案。
- 区分 `food_guidance`（疾病/目标的食材建议）与 `recipe_selection`（实际本餐选菜）。疾病不由症状推断，减脂不映射为肥胖，增肌不映射为肌少症。
- 必要适用条件来自逐项明确自述/内部显式 context；成人、分型、分期、透析和训练等未知不默认补齐。非关键缺项只影响相关指导，不普遍索取身高体重，不生成全天营养处方。

## 知识与映射

- 疾病主路径读取冻结 v2 的124条直接食物指导；成分关系保持研究解释用途，不自动转为食物动作。
- 新目标主题、原文短摘、定性指导及适用条件写独立版本化研究资料；证据按来源定位与hash核对，注明项目整理/解释、专业待审，数值摄入目标不在本轮范围。
- 食材映射使用显式知识对象ID→目录食材名/ID清单；不以宽泛别名、字符串包含或成分机制自动扩展。缺映射独立报告，不能当成反向证据。
- 原始包、001/002/003研究SQL与旧向量索引不变。新增研究资料可用追加快照表持久化，个人档案及查询不落公共知识库。

## 输出

- 每条指导包括稳定ID、所属疾病/目标、对象及方向、条件、适用状态、事实/支持/限定证据与出处；另列未知条件、未覆盖主题、映射缺口及冲突。
- 建议显示沿用 `FoodSuggestion` 和主题归属，接受/取消记录仍由用户选择；研究依据单独随本次回复返回，不把旧接受记录当最新证据。
- 每个候选配方绑定内容版本/hash、recipe/variant、配料行和主做法hash及匹配指导。食品类别用明确成员映射，工艺只对实际主做法验证，不混用备选方法。
- 健康理由只能使用当前匹配指导的程序化说明和真实本餐检查；模型仅提交候选ID与本餐说明，程序按实际配方形成指导/事实/原文关联。不采信模型自由填写的引用或健康陈述，避免模型误填ID导致可行整餐被拒，或仅凭合法ID发布任意健康陈述。

## 推荐与失效

- 复用现有资格、食材有无及整套餐条件核验和模型选菜流程；过敏忌口、有效避开及补买等硬限制优先。已适用的研究避开项只作为本次实验筛选，不修改用户保存设置；少选用于排序/提示，不等于硬禁。
- 本地研究接入的生成提示不允许引用未提供指导或目录外菜品。未覆盖/缺必要条件只保留相关健康判断，不因无健康匹配就一律拦截正常本餐；仍可让模型选择合格配方并明确未作健康适宜性结论。真实硬限制不放宽，不静默回退普通推荐，也不冒充完整健康评估。已有可行候选时，模型无依据拒选属于生成未完成，不能冒充没有可做的菜。
- 缺失或撤回必需证据不得使用；提供指导前、模型返回后及最终响应前核对最新水位。游标绑定知识/映射版本，分页和手选口味重新校验但不额外调用模型；撤回或配方变化使旧依据失效。
- 本地 provider 显式注入并校验 local/loopback；云端入口不默认配置。模型调用沿用固定地址、账户认领、无自动重试；常规自动检查使用构造fetch。11月5日代理1元内真实界面验证已完成5次并结项，费用/失败记录独立保留，不自动使用余额继续调用；用户主动预览与旧脚本授权分开。

## 验收与数据划分

- 在实现前登记解析/映射、食材方向和完整本餐样例规范；gold 与业务数据隔离，不注入模型。开发集可调试，预留验收集只作最终比较；二者均是项目构造集，未经真实独立人审不称独立人工金标准。
- 覆盖仅疾病、仅减脂、仅增肌、组合、未知必要条件、过敏/忌口、少选、已接受避开、库存/调料/补买、配方变更、撤回、非法指导ID、无候选、分页/口味/换菜。
- 报告指导覆盖/缺口、映射覆盖、硬限制结果、实际菜谱及理由支持；不能用原27题Recall@10或一般模型选菜通过代替本餐RAG验收。
- 真实PG回读、构造模型端到端、真实模型生成、人工质量与部署分别记录；11月5日已有5次真实界面样本，失败也保留。样本不足以证明泛化质量，独立人工/专业质量仍保留待验收。
