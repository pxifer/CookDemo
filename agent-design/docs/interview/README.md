## 面试前的最短准备路径

1. 用自己的话讲项目故事，能区分“真实菜谱业务”与“研究证据问答”。
2. 看参数实测，记住实际值和适用入口，而不是背行业默认值。
3. 讲清2个真实失败：普通菜无依据拒选、模型错挂引用；再补导航旧引用P2。
4. 手算RRF/Recall，亲手跑本手册离线练习；没亲自完成前不宣称已完成。
5. 用实验账本回答“对比过吗”。当前没有证据支持混合优于A1，也没有启用专用reranker。
