# RAG优化复核与疾病扩库 v2

日期：2026-10-28（Asia/Shanghai）。依据[健康RAG方案](../retrieval/health-rag-plan.md)、[优化选型路线](../../docs/agent-interview-2026-10-28/03_拾味RAG与Agent优化选型及实施路线.md)、v1知识包和实际检索/仓储代码。本轮用户要求检查RAG搭建能否优化，并继续扩展疾病类型入库。

结论：现有PostgreSQL权威事实、研究/正式发布分层及可选pgvector方向可以保留。当前最直接的问题在中文实体解析、查询契约和版本完整性，而非必须增加图数据库、Agent框架或向量服务。本轮已实现A1词法、缓存与完整性、证据完整包及四病种扩库；向量和线上医疗规则仍未启用。

## 已核实问题与实际修正

| 发现 | 实际修正 | 验证 |
| --- | --- | --- |
| 实体子串会同时命中“不饱和脂肪酸”和“饱和脂肪酸” | NFKC后做受控最长非重叠匹配，同跨度多实体返回歧义；关系端点按已解析类型过滤 | 不饱和查询不再把饱和脂肪关系当精确对象 |
| 连续中文长句常被当作整块关键词，低召回；通用词又可能误召回 | 保留实体短语，辅以中文二元片段、英文词与通用词过滤；保留否定提示 | 长句、未知食物、否定、短词碰撞案例 |
| 食品形态和疾病分型不明仍可能混出结果 | 香菇鲜/干、泛称糖尿病/肾病/骨质疏松返回待确认；显式已确认2型参数不重复询问 | 鲜香菇不混入干香菇值；未把骨质疏松自动确认为原发性 |
| 一项总分混合身份命中和关键词，难以解释 | 实体与词法分别排名，RRF融合并返回两通道排名及命中词；以稳定ID收尾 | 保留A0并做同包对照；不是BM25或dense混合检索 |
| 缺少独立于top-k的必取证据通道 | 服务端内部`requiredEvidenceIds`放独立集合，补齐相关限定；缺失/撤回返回`evidence_missing` | `topK=1`仍带必需依据和例外，未用相关性替代必需证据 |
| 每条关系重复线性查来源/证据、每次查询重载全库 | 缓存实体/来源/证据映射；仓储最多缓存2个经校验不可变快照 | 第二次load不重查事实表；对象深冻结；每次仍查撤回 |
| 仓储load硬编码日期、丢失部分boundaries，未校验整包回读 | 新增`002-integrity.sql`保存元数据与跨JSONB键序的规范hash；回读验证，hash排序不依赖系统locale | 日期、边界完整保留，回读整包hash匹配 |
| 数据可能原地修改，缓存的不可变假设没有约束 | 研究表和快照禁止UPDATE/DELETE，变更需新bundle；撤回表只追加 | 更新事实、删除撤回均被拒绝；不覆盖旧迁移001 |
| 每版本一个本地目录使撤回无法跨版本共享 | v1/v2导入同一研究数据库，撤回跨bundle；核对旧库撤回并迁移 | 本机旧库撤回0条；共享库两个版本均存在；跨版本撤回测试通过 |
| 仅查询开始读一次撤回 | 返回前再次读取全局撤回并在变化时重算，输出水位hash | 缓存命中仍不会复活已撤回来源；额外覆盖查询期间撤回竞态 |

否定提示只用于解释检索意图，不会自动修改健康档案或反转既有事实。中文二元片段是轻量回退，不是完整中文语义理解；拼写纠错、复杂比较关系和临床问句理解尚未完整实现。缓存依赖研究写入不可变约束，不宣称可以抵抗数据库管理员主动移除约束。当前仍在应用内运行研究查询，GIN已存在不等于已测SQL全文。

## 扩展后的知识库

版本`health-kb-2026-10-28-v2`，增加高脂血症、成人肥胖症、成人慢性肾脏病、成人原发性骨质疏松症四个疾病主题。加上v1高血压、成人2型糖尿病、痛风、高尿酸血症，共8个疾病实体。这里的“主题”不代表已正式开放8种疾病的推荐或任意组合。

新增4份国家卫健委编制/国家疾控机构公开来源、45个证据单元和105条关系；总计11来源、137实体、98证据、260关系、124条草稿规则。v1的来源、实体、证据、事实、草稿和冲突逐条完全保留，另存新版本；临床正式发布及真实菜谱绑定仍为0。

新增来源：

- 中国疾控中心公开的[成人高脂血症食养指南（2023年版）](https://www.chinacdc.cn/jkyj/yyyjk2/jswj13949/202504/t20250407_305765.html)。该页面是3张长图，附件栏为空；已对首张图中印刷页2、5–7的相关条目目视核对。10条短摘保存印刷页、图像URL/hash及像素区域，不冒充PDF或OCR字符定位。
- 国家卫健委[成人肥胖食养指南（2024年版）](https://www.hncdc.com/upload/1/cms/content/editor/1741857710156.pdf)，湖南省疾控公开副本。保留无复杂合并症、妊娠/哺乳等范围，未输出个人极低热量、断食或代餐处方。
- 国家卫健委[成人慢性肾脏病食养指南（2024年版）](https://www.hncdc.com/upload/1/cms/content/editor/1741857710741.pdf)，湖南省疾控公开副本。保留分期、透析、血钾、尿量、水肿和个性化营养计划条件，未一律禁钾、禁蛋白或套用痛风饮水量。
- 中国疾控营养与健康所公开的[成人骨质疏松症食养指南及问答（2026年版）](https://www.chinanutri.cn/fgbz/fgbzjszn/202605/t20260526_1836069.html)。从RAR中只读提取主指南，保存PDF与压缩包hash及成员名。首批限定成人原发性，未把继发性、特发性或儿童病例混入，也未生成补充剂用药剂量。

慢性肾病与原发性骨质疏松的蛋白建议可能不一致，已新增跨疾病适用性冲突记录；不机械平均、不直接取最严、不以有益项抵消必要限制。没有专业组合方案时不宣称组合可执行。

所有新规则仍为`draft`、`clinicalReview:pending`；`source_checked`表示项目代理核对来源，不能写成来源机构审核了本项目关系。查询不写公共库，未新增模型调用或收费资源。

## 继续优化的优先顺序

1. **真实菜谱绑定及独立评测**：按实际bundle/hash/recipe/variant/method建立受控食品、工艺映射；建立按来源/主题隔离的200题候选和人工标注规范。当前没有为满足数量机械生成200题或改动普通菜谱资格。
2. **正式发布层**：继续按既有路线另建专业审核、批准快照、发布指针和绑定层，研究schema仍只允许草稿。不能把来源核对当临床批准。
3. **数据库检索通道**：用同契约比较应用内A1与有界PG全文/RPC，测真实PG连接及CloudBase能力；当前JSONB/GIN结构只是准备，不改名为BM25。
4. **向量/重排**：再对照BGE/Qwen并同时解决运行时query编码、协议hash、维度及预算，必要证据仍单独带回。没有目标环境结果前，不新增独立向量服务或宣布某模型最优。
5. **长会话及Agent**：只在检索/发布依赖完成后推进token预算、内存摘要与有界只读状态机；不默认增加多轮个人Key消耗。

新优化相对原路线是可逆、局部、可验证的实施，不更改个人资料保留策略、普通推荐和线上健康发布边界。
