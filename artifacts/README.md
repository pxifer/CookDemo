# 输出、证据与临时文件

| 目录 | 保留策略 |
| --- | --- |
| `build/web/` | 可重新构建的页面与静态资源副本，Git 忽略；不是图片源目录 |
| `acceptance/` | 历史测试、来源及发布证据；整体迁移，原始报告字节与 hash 保留 |
| `review/` | 历史评审附件及截图，保留证据 |
| `test-results/` | Playwright 运行输出，Git 忽略；需要长期证明的文件应另行归档到验收目录 |
| `tmp/` | 临时处理与来源缓存；`health-sources/` 仍有知识库离线重建价值，不能一键清空 |

历史报告内的旧路径、命令和源码指纹描述原版本，通过[迁移映射](../docs/maintenance/reorganization-2026-11-03/migration-map.json)查找新位置；不要改写原报告来制造新版本通过。整理后的测试写新目录。
