# 独立评测审核材料

本包有200条候选题，尚未经过独立标注或真实模型评测。它不是“200题通过”的证据。

1. 分维度阅读五份Markdown，按caseId在cases-for-independent-review.json填写修订。保留clusterId，近义改写不可跨开发/留出集。
2. 用recipe-index核对配料、固定用量、口味和独立做法；用fact-index、evidence-index的定位和原始来源链接核对条件、撤回与适用范围。
3. 自动候选中的场景/任务并非都已转成完整用户输入。finalModelInput必须补齐；补买、数量、过敏、疾病/目标及期望状态需明确，不能临时看模型答复修改答案。
4. 审核者须独立于出题/实现者。疾病题至少两位不同审核者，并记录裁决；sourceVerified/reviewedAt/reviewers不能自动填写。正式临床能力仍不在当前发布范围。
5. 审核完成后才可调用现有evaluation:freeze冻结到新文件。冻结器检查元数据和分组，不能替代来源、输入完整性和独立性的人工核查。
6. 本包未调用模型。真实输出留空；后续专用Key调用受5元预算账本限制，不拿mock或自动契约代替质量分。

严重漏排、未知冒充安全、疾病疗效保证、虚构配方或截断做法均需明确标错，修复后重新验证。病例题依然是构造输入，不能混入真实个人健康资料。
