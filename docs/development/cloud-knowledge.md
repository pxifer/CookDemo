# 版本化公开知识接线

用户于2026-11-13明确选择“开发云端知识接线并上线，让网站AI实际引用最新知识”。KB-001基于已发布main13f2d6f，在独立任务目录实现。部署及实际验收以管理发布记录为准，本文不是已上线声明。

云端通过既有Data API的匿名只读角色读取独立 `shiwei_knowledge_releases`，仅含公共知识、受控映射及撤回ID。`KNOWLEDGE_RELEASE_ID/SHA256`绑定完整不可变快照，缺失/撤回/变更/网络失败拒绝旧依据；运行期间不写入公共表、不上传个人问题、档案、向量或调用记录。旧知识包不覆盖，撤回集合只增不减，历史不可删除。

发布入口使用 `publishedKnowledge`，不启用只允许回环的 `foodGuidance`，也不注入旧HealthModel。聊天沿用账户个人Key、共享PG单次认领与原有超时/不重试，注入适用指导、限定证据、原则与受控营养查询参考；展示的食材建议由实际目录及程序条件生成，不采纳模型自造建议。实际选菜继续由模型选目录ID，程序绑定真实配方、排除适用避开项、核对整餐，游标绑定依据指纹。来源及撤回变化后返回前复核。

来源资料仍未临床签认，`clinicalRelease=null`；不保证整菜营养达标。组成值保留每100g可食部、具体形态及美国历史参考边界，缺失不是零，不转换成个人摄入或全天目标。全量源事实留在受控公开快照，模型上下文有调用前预算，超出拒绝而不截断限定条件。未覆盖关注不外推为安全。

构建工具 `scripts/build-public-knowledge.ts <新目录> <权威撤回ID数组文件>`：验证已有源资产，固定版本hash，输出公开payload、manifest和一次性发布事务。输入撤回ID须来自本地权威研究库，不能用空数组代替已有撤回。SQL仅新增独立公开表及版本，不改账户、菜谱表或旧研究迁移；不重复执行已发布SQL。匿名只能读published行，无写权限。

本地测试 `tests/cloud-knowledge.test.ts` 覆盖匿名权限、不可变/撤回、个人Key和共享认领、故障不沿用旧依据、提示来源及预算/B7缺项；均使用本地PGlite及构造供应商，不冒充真实云PG、真实模型或临床质量验证。云端发布只做必要只读状态和知识hash核验，不使用真实账户或Key测试。
