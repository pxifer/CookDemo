## 葱烧豆腐

<a id="r026"></a>

### 口味：葱香酱香 · R026

**主料**

- 豆腐700克

**辅料**

- 葱白200克

**调味料**

- 食用油100克、八角2个
- 盐5克、味精2克、酱油50克
- 水淀粉10克、葱油10克、清水适量

**做法**

1. 豆腐切厚三角片；葱白纵向剖开，再斜切成约6毫米宽的眉毛葱。
2. 热油加入八角和一半葱白，大火炒黄，捞出葱料后降低火力。
3. 豆腐沿锅边下锅，中火煎至两面金黄。
4. 先烹酱油，再加水与煸好的葱，用盐、味精调味，小火烧约3分钟。
5. 加入余下葱白，淋水淀粉收成芡汁，最后加葱油出锅。

来源：[Sherlock｜标题注明大厨隋坡版](https://halo.sherlocky.com/archives/chihuo)。 个人转记；不是已对照原视频的隋坡原方。

## 豆腐烧小白菜

<a id="r027"></a>

### 口味：咸鲜酱香 · R027

**主料**

- 豆腐400克
- 小白菜250克

**辅料**

- 蒜片、葱花适量

**调味料**

- 食用油、酱油、水淀粉、清水适量
- 盐：烧豆腐用1.5克，煎豆腐与炒菜另用适量
- 花椒油可选

**做法**

1. 豆腐切约1厘米厚片，锅中放油并撒盐，煎至两面金黄取出；小白菜梗叶分开。
2. 补油先炒菜梗并加盐，半熟时放菜叶，炒出水后盛出沥水。
3. 少油把蒜片煎黄，下葱花炒香，烹酱油后放豆腐。
4. 加刚没过豆腐的水和盐1.5克，小火烧约2分钟。
5. 转大火铺入白菜，盖约1分钟，翻匀并收汁，勾薄芡；来源允许出锅前少量花椒油。

来源：[陳某乎喔｜注明来自隋卞做](https://m.xiachufang.com/recipe/107347081/)。 网友整理版，完整文字流程可读；未与厨师原视频逐项对照。

## 蒜蓉西兰花

<a id="r061"></a>

### 口味：蒜香咸鲜 · R061

**主料**

- 西兰花200克

**辅料**

- 蒜20克

**调味料**

- 盐5克、鸡精适量、食用油15毫升、水淀粉10毫升
- 焯水用盐和油另适量

**做法**

1. 西兰花洗净切小朵，蒜切末。
2. 沸水加少量盐油，西兰花焯过捞出。
3. 锅内用15毫升油炒香蒜末，下西兰花翻炒。
4. 加盐、鸡精炒匀，接近成熟时加水淀粉勾薄芡，炒至芡汁略浓盛出。

来源：[绮梦无多｜美食天下](https://home.meishichina.com/recipe-205362.html)。 用量及流程据原站检索文字；盐量保留原数，待试做核验。

<a id="r062"></a>

### 口味：蒜香咸鲜 · R062

**主料**

- 西兰花适量

**辅料**

- 蒜适量

**调味料**

- 盐、鸡精、玉米油或葵花籽油适量

**做法**

1. 西兰花掰小朵，茎去老皮保留嫩部，冲洗并用盐水浸泡后沥出。
2. 沸水中焯西兰花后捞出，蒜切末。
3. 油热炒香蒜末，下西兰花快速翻炒至熟。
4. 加入盐和鸡精，炒匀装盘；原文没有勾芡环节。

来源：[蔬菜苞苞｜美食天下](https://m.meishichina.com/blog/602307/)。 与勾薄芡版同菜同味，保留两份做法供后续试做决定。

## 拍黄瓜

<a id="r063"></a>

### 口味：蒜香酸辣 · R063

**主料**

- 黄瓜2根

**辅料**

- 蒜2瓣

**调味料**

- 盐、味精、醋、辣椒油适量
- 清洗用小苏打：来源未给用量

**做法**

1. 黄瓜洗净后逐根拍裂，再切成入口大小的小块；大蒜拍松后切碎。
2. 将黄瓜和蒜末放入拌菜盆，加入盐、味精和醋，充分翻拌均匀。
3. 把拌好的黄瓜盛入盘中，按口味淋上辣椒油即可。

来源：[家yao｜美食天下](https://home.meishichina.com/recipe-373570.html)。 保留实际调味，不补生抽或糖；原文的摆拍步骤已去除。

## 擂椒皮蛋

<a id="r064"></a>

### 口味：烧椒酸辣 · R064

**主料**

- 青椒、皮蛋各适量

**辅料**

- 蒜末1勺

**调味料**

- 盐少许、香醋2勺、生抽2勺、香油1勺、糖半勺

**做法**

1. 青椒洗净，直接放热锅，用中火烘煎并不断按压，翻面煎至两面虎皮且完全变软。
2. 关火后再利用余热烘一下，盛出稍凉，剥掉外层表皮；皮蛋去壳。
3. 青椒和皮蛋放入捣臼，加蒜末及全部调味料。
4. 捣碎拌匀后装盘。

来源：[爷俩儿好菜｜抖音索引文稿](https://www.douyin.com/shipin/7263326191615215676)。 账号身份有依据；本配方来自带识别错字的索引文稿，未逐段对照视频，暂放待验证。

## 酸辣土豆丝

<a id="r067"></a>

### 口味：酸辣 · R067

**主料**

- 土豆适量

**辅料**

- 干辣椒、蒜片、葱段、鲜辣椒丝适量

**调味料**

- 食用油、醋、生抽、糖、鸡精、香油适量

**做法**

1. 土豆切丝；干辣椒先泡过再切段。
2. 土豆丝焯约10秒至略透明，沥出。
3. 热锅凉油煸香干辣椒，下蒜片和一部分葱段。
4. 倒土豆丝大火炒，沿锅边烹醋，用生抽、糖、鸡精调味。
5. 加余下葱段、鲜辣椒丝、香油，临出再烹醋，炒熟装盘。

来源：[CaCa需停止消极｜注明小红书爷俩儿好菜](https://www.xiachufang.com/recipe/107270943/)。 与同页干锅花菜是两道独立菜；未混入页面另记的村驴版。
