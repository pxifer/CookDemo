## 酸辣汤（豆腐木耳版）

<a id="r034"></a>

### 口味：胡椒酸辣 · R034

**主料**

- 老豆腐、泡发木耳适量
- 鸡蛋2个

**辅料**

- 葱白末、香菜末适量

**调味料**

- 食用油、盐、酱油、白胡椒粉、醋、香油、水淀粉、清水适量

**做法**

1. 豆腐和泡发木耳切丝，在加盐的沸水中烫过，捞出用凉水降温。
2. 油热炒香葱白和少量酱油，下豆腐、木耳与水，加盐、酱油、白胡椒粉煮开。
3. 盛汤碗放香菜、醋、白胡椒粉和香油；鸡蛋打匀，另调水淀粉。
4. 水淀粉分2—3次加入沸汤，调至需要的稠度。
5. 沿锅边淋蛋液，待凝结后轻推；起锅前再加少量醋，倒入备好的碗中。

来源：[做饭的小勾勾｜注明搬运老饭骨](https://m.xiachufang.com/recipe/106127533/)。 原文对末次醋是否可并入碗底有疑问；这里保留两次加醋的正文流程，酸度用量待核。

## 番茄蛋花汤

<a id="r057"></a>

### 口味：咸鲜带番茄酸味 · R057

**主料**

- 番茄2个
- 鸡蛋2个

**辅料**

- 葱适量

**调味料**

- 盐6—8克、开水800克
- 玉米淀粉10克、水50克（调淀粉水）
- 食用油适量

**做法**

1. 番茄烫后去皮切丁，鸡蛋打匀，葱白葱叶切开备用。
2. 热锅凉油炒香葱白，下番茄炒出汁，倒800克开水并加盐。
3. 汤滚开后加入用10克玉米淀粉和50克水调好的淀粉水。
4. 保持汤翻滚，用勺分次把蛋液倾入，形成较大蛋花。
5. 再煮约1分钟，撒葱花盛出。

来源：[欢欢早安｜下厨房](https://m.xiachufang.com/recipe/106424639/)。 盐量照录，待试做定量；与另一份同味汤的蛋花火候差异保留参考。

<a id="r058"></a>

### 口味：咸鲜带番茄酸味 · R058

**主料**

- 番茄1个
- 鸡蛋2个

**辅料**

- 葱花适量

**调味料**

- 植物油、盐、鸡精、清水适量
- 水淀粉可选，来源未定量

**做法**

1. 番茄用开水烫后去皮切块，鸡蛋打散至蛋黄蛋白均匀。
2. 油热后炒番茄，再倒清水，煮开后继续约5分钟；来源允许此时加水淀粉。
3. 转小火，使汤微沸，倒蛋液；凝结后再轻搅。
4. 关火后调盐和鸡精，撒葱花装碗。

来源：[溪边花园Amy｜下厨房](https://www.xiachufang.com/recipe/100511045/)。 步骤据原站检索文字；不是已完成试做的版本。
