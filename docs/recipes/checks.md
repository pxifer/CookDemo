| 完整流程与不同菜品 | 392份完整文字流程、364道不同菜品；另6份旧缺项不计完整数。地域、设备、口味和多来源版本不重复增加菜品数 |

| 网站分类 | 荤菜254、蔬菜豆蛋108、汤30份做法；六类目录、16份新增分册与此前正文并存 |

| 空白检查 | 涉及的已跟踪说明文件通过Git空白检查；新正文、目录及整理副本通过编码与行尾空白检查 |
| 同味与异味 | 6组同味方法初步对照；咖喱果香／椰香、番茄糖醋／酱油糖醋及番茄炒蛋酸甜／咸鲜走普通口味核验，不算冲突 |

初次检查发现一份来源被抽成单步、一处社区配料中的图片残留，以及说明文件行尾空白。复核前两份原方后，发现麻辣鸡凉粉碗汁省略、葱烧海参生抽5／10克不一致，已移出完整数量并列入补核；图片残留及空白也已处理，复查无上述失败项。

人工抽核与异常复核包括：气泡虾中的“酸奶状”没有当成酸奶食材；中式炸鸡的冷藏3小时、中火5分钟及大火2分钟按原文校正；鱼香茄子的猪臀肉150克及蒸15分钟保留；八宝葫芦鸭的整鸭、芡实、瑶柱等未遗漏。只读到标题、关键操作仅在图片、混合多套方或配料表与流程不符的版本未凑数。

以上证明文档的一致性和已发现问题的修复，不证明每份配方已试做。机构原页／署名、原视频简介、网友转记和社区文字的证据强度不同；并未逐段观看所有视频或核读所有用户评论。快手、微信视频号尚无本轮可计数的完整原视频配方，小红书4份为转记、抖音2份为文稿，保持待验证。

仍未完成：全量原方及视频画面对照、原料表与操作量逐项审核、复合调料成分映射、固定量和口味试做、复用授权、正式审核导入、营养与具体模型接入。没有改PRD、TDD、运行时代码、数据库或云资源。整理JSONL不属于可直接发布的内容包。
