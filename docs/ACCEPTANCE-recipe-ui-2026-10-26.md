# 菜谱界面七项修复

日期：2026-10-26（Asia/Shanghai）。范围为用户本轮截图反馈，代码及本地验证完成；随后已按用户明确要求随v30合并发布，上线与线上验证见[工作台交互修复](ACCEPTANCE-workspace-ui-2026-10-26.md)。

- 固定配方展示：凉拌黄瓜的醋、酱油、盐、香油公式分别展开为11.5ml、7.5ml、0.6g、7ml；同类“原文每份”“步骤给出”编辑标记移除。葱煎豆腐、韭菜炒蛋按同一固定批量处理；原始数据保留，用餐人数不参与计算。
- 工作台缩略图完整适配图片区域，详情图片按原始比例显示，移除固定高度裁切；无图菜仍使用菜名占位。
- 图鉴与工作台详情中的来源保留纯文字署名，移除链接和跳转箭头，内部原始出处仍保留。
- 每页底部本餐补买清单保留一层展开，直接显示条目；每道菜自身补买清单继续可用。
- 图鉴详情做法结束后，右下角新增“返回菜谱图鉴”按钮。
- 在布局完成、首帧绘制前将详情滚动位置立即设置为顶部，不执行平滑回顶。
- 打开详情前将图鉴的滚动位置保存到对应浏览器历史记录。顶部、底部返回以及浏览器后退恢复原位置、筛选、页码与点选菜品焦点；切换口味不覆盖历史状态。

验证：`scripts/run.ps1 build`；`recipe-copy.test.ts`、`cloudbase-http.test.ts`、`gallery-content.test.ts`、`library-state.test.ts` 合计19项通过。

`scripts/verify-recipe-ui-local.ts` 使用既有发布配方和本地图片，以本地 Fastify 注入模拟 HTTPS 请求，未访问线上服务。Edge 桌面1440×1000、手机390×844，开启正常动效。分别从图鉴第二页1880px、2804px处打开做法，记录详情首帧均为0px，返回精确恢复原位置；覆盖浏览器前进/后退、详情刷新后返回、两个返回按钮、来源无链接、补买展开无嵌套、图片比例及无横向溢出。
