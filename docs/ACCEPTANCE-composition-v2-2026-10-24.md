# 过敏、忌口成分关联修复与逐方核验续接

本轮来源：用户指出鱼、玉米限制仍导致大量无结果，要求由实施人员收集原方和成分信息，不再依赖用户提供复现材料。沿用 D15-02 的逐方核验方案；不修改 PRD，不推定未知复合调料成分完整。

## 根因与改动

- 上一版只增加两份候选配方的完整核验，不能代表全部145道菜已支持过敏/忌口。其余候选仍被配方门禁拦截。
- 鱼种、鱼露/鱼丸及玉米粒/玉米淀粉与限制对象缺少关联。本轮加入17条有明确正向命名依据的 contains 关系；不把名称里出现“鱼”的蒸鱼豉油或鱼香菜名直接当含鱼证明。
- 普通原料、明确可省项、步骤投料和模糊商品配料混在一起。核对9份固定提交原文，修正6份配方中的可省项、漏收的油/水/盐/可选虾和末步；未知用量仍为 null，不从简介导入热量或健康功效。
- 淀粉/水淀粉不能证明玉米或小麦来源；“食用油”不能证明没有玉米油、花生油、大豆油或调和油。即使旧基础食物带有完备标记，也在本次运行时明确保留来源不明拦截。不限调料只豁免库存，仍执行这些限制。
- 先报告明确命中的限制成分，再执行完整性检查。没有结果时只取与现有主料有关的最多三项原因，移除全目录前五道无关菜的错误提示。
