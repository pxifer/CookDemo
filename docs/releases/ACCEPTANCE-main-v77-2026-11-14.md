# main-v77：公开署名只显示来源名

2026-11-14。仅后端展示逻辑，未改内容版本（仍 `gallery-listed-foods-1000-20261114-v3`）。

## 问题

详情弹层把整条出处原文当作署名显示：

```
来源：小鹿yoyo｜标题王刚版
来源：好豆菜谱（MIRecipe公开存档）
来源：夏叔厨房／B站原视频简介
来源：央视网《回家吃饭》｜演示嘉宾石小满
```

首个分隔符或括号之后是**对出处的注释**（谁转记的、标题写着谁、存档从哪来），不是来源名本身。

## 修正

新增 `shared/attribution.ts`：`publicAttributionLabel` 在第一个 `｜ | ／ / （ ( 【 [` 处截断，并去掉尾部标点与空白。

- `《》` 不截断：`央视网《天天饮食》` 是节目名，不是注释。
- 截断后为空时回退到去掉前导分隔符的原串，不产出空署名。
- **存储的 `author` 原样保留**，只简化展示标签；原始出处与"网友整理/不能视作本人原方"等判定仍可追溯。
