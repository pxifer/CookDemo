# main-v92：补买清单拆分食材与调料

2026-11-15。只发代码，内容版本不变（仍 `gallery-listed-foods-1000-20261114-v3`）。

## 问题

补买清单把调料和食材混在一起（姜、鸡精、香叶、八角、冰糖……），看起来像“食材缺料”。同时“姜 15g”和“姜片”会各占一行，调料内部的同名项也没有合并。

## 处理

1. **按菜谱声明的主料/辅料/调料角色分流**：`role=seasoning` 进“调料”组，其余进“食材”组；不再用名称猜类别。
2. **两组分开展示**：单菜“补买 N 项”和整餐“本餐补买清单”都带“食材 / 调料”小标题，不再混排。
3. **不限调料时完全不列**：`只使用家里现有的调料` 关闭时，调料组为空；开启时，缺失调料才进“调料”组。
4. **调料按库存键合并**：姜 / 姜片 / 姜末 → 姜，葱段 / 葱花 → 葱，蒜末 / 蒜瓣 → 蒜，避免同一调料多行。
5. 沿用上一步的数量规则：同单位求和、不同单位分开、范围与未知用量不求和；已知量 + 未注明用量折叠为“（另有用量未注明）”。
