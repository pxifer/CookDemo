# 过敏与忌口逐项匹配修复（2026-10-25）

## 本地实现

- 过敏和明确忌口现在逐项检查所选口味中实际使用的配料行。检查食材 ID、目录 `contains` 关系、登记过敏原及逐配方已核验的等价食材。
- 配方中无关配料的来源核验缺项不再拦截整道菜；没有 composition approval 的菜也执行同一套明列配料匹配。
- 对当前限制确实相关、来源仍未知的淀粉和通用食用油继续拦截，例如玉米相关限制下的淀粉、玉米/花生/大豆相关限制下的来源不明食用油。
