# 用户食材用量仅作参考：实现与本地验收

日期：2026-11-05。依据：[D19-13](../product/decision-log.md)。范围为普通及AI选菜；没有升级依赖、改动菜谱/知识包、执行云端发布或新增真实模型调用。

## 行为

- 白菜1g、白菜99999g和白菜未填量在推荐中均表示“有白菜”，不因填写量产生不同资格、排序、自动菜数或累计缺额。
- 输入框保留参考量和单位；只改量不清空结果、不自动请求、不使普通/AI分页游标过期。同名量采用最新非空值，不叠加或阻断。
- 食材有无、明确形态匹配、人数、自定义数量、过敏忌口、有效AI避开、调料与补买规则继续执行。缺必需食材且不补买仍不能选。
- 菜谱原用量、步骤和标准配方营养保持；这次不会证明实际库存足够，也不按填写量计算营养。
