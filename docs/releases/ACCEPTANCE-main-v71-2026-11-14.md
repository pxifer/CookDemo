# main-v71：食材下拉按宽食材归并

2026-11-14 01:0x 更新既有 CloudBase HTTP 函数成功。

## 改动

下拉不再逐条列具体部位/物种，而是归并到能覆盖菜谱的宽食材：

- 五花肉、里脊、梅花肉、排骨、肉馅 → **猪肉**
- 鸡腿、鸡翅、鸡架、本地鸡、鸡胸脯肉 → **鸡肉**
- 牛腩、肥牛、牛排 → **牛肉**；羊排、羊腿 → **羊肉**
- 海鱼、黄鱼、鲈鱼等 → **鱼**；河虾、黑虎虾 → **虾**
- 花蛤、扇贝、生蚝 → **贝类**；海蟹、梭子蟹 → **蟹**
- 鸭腿、鸭翅 → **鸭肉**；鹅肉 → **鹅肉**
- 西红柿 → **番茄**（同义词归并）

选择“猪肉”仍会通过既有的 family 匹配覆盖五花肉、里脊、肉馅等具体部位，不会因为下拉简化而漏掉菜谱。食材仍只来自 1000 道已发布菜谱的主料/辅料，腌料/调味料不进入。

## 边界

宽食材归并依赖于既有的 family 规则；若某个具体部位不在 family 正则内，仍可能作为单独条目出现。本次已覆盖猪/牛/羊/鸡/鸭/鹅/鱼/虾/蟹/贝及番茄同义词。
