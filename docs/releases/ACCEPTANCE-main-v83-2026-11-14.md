# main-v83：高频同义词表

2026-11-14。仅匹配与归并规则，未改内容版本（仍 `gallery-listed-foods-1000-20261114-v3`）。

## 原则

只收**同一件要买的东西的不同叫法**（地区叫法、写法差异），不收"相似但是不同商品"的东西。

同组**双向**成立：有圆葱可以做要洋葱的菜，反之亦然。

## 刻意不合并

`青椒 / 红椒`、`大白菜 / 小白菜`、`大葱 / 小葱`、`猪肉 / 排骨`——它们相近但属于不同商品，合并会让"有青椒"错误覆盖"要红椒"的菜。
