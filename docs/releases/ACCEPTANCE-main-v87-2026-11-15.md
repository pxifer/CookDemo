# main-v87：菜数改为“不限数量 / 按荤素汤”，移除人数

2026-11-15。只发代码，内容版本不变（仍 `gallery-listed-foods-1000-20261114-v3`）。决策依据见 [D19-14](../product/decision-log.md)。

## 变更

1. **移除人数**：`Meal.servings`、`Extraction.servings`、健康输入理解人数、人数校验与配菜参考弹层全部删除。文字里的“2 个人吃”只剥离，不再推断菜数。
2. **菜数两态**：`auto`=不限数量，按食材匹配浏览；`custom`=按荤、素、汤三个下拉凑齐。补买只决定能否缺料，不再切换模式。
3. **不限数量仍受食材映射限制**：不补买时只保留现有食材能完整做的菜；补买时每道菜至少复用一个现有主料，不会变成全库目录。
4. **按荤素汤补买不凑数**：每道菜同样必须复用现有主料；凑不齐返回实际数量与分类缺额。
5. **结果区**：配齐显示“已按 X 荤 Y 素 Z 汤配齐”，不足显示“还缺：荤菜 X 道 · 素菜 Y 道 · 汤 Z 道”，并提供“允许补买 / 改成不限数量”。副标题改为状态句，不再出现“每页 6 道”。
6. **过渡兼容**：旧页面仍可能提交 `servings`，本次 Schema 接受并忽略该字段，下个版本再删。
