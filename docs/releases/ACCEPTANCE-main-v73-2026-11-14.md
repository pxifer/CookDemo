# main-v73：食材下拉审计与脏词过滤

2026-11-14 01:5x 更新既有 CloudBase HTTP 函数成功。

## 定位到的问题

食材下拉的数据来自 1000 道菜谱的主料/辅料。导入时把**数量、单位、碎片**也当成了食材，例如：

- 一大块、一到、一朵、中等、适量、少许、若干
- 一根、一个、一块、一片、一条、半个、900g
- 小肠、筒子骨等具体部位

另有大量蛋类细分：蛋液、土鸡蛋、笨鸡蛋、常温鸡蛋、蛋黄、鸡蛋干、咸鸭蛋、皮蛋、鹌鹑蛋、鸽子蛋等。

## 修正

- 新增 `isInvalidFoodName`：数量词、单位、碎片、纯数字不再进入下拉。
- 蛋类归并：鸡蛋/蛋液/土鸡蛋/笨鸡蛋/常温鸡蛋/蛋黄/鸡蛋干 → **鸡蛋**；咸鸭蛋 → **鸭蛋**；皮蛋、鹌鹑蛋、鸽子蛋保留。
- 具体部位继续归并：猪大肠/猪肚/猪血/猪肝/筒子骨/小肠 → **猪肉**；羊里脊 → 羊肉；樱桃谷鸭子 → 鸭肉；仔鸡 → 鸡肉。
- 小根蒜 → 蒜、甜酒酿 → 酒酿，按调料排除。
- 收敛猪肉 family 正则，避免“心/骨”等单字误匹配导致推荐回归（已用既有 341 道快照回归验证）。

## 审核范围说明

- 本地 341 道内容快照：下拉中未再发现数量/单位脏词。
