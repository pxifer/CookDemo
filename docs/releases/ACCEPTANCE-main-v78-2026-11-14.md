# main-v78：署名分隔符覆盖到任意分隔符

2026-11-14。仅后端展示逻辑，未改内容版本（仍 `gallery-listed-foods-1000-20261114-v3`）。

v77 只处理了 `｜ | ／ / （ ( 【 [`。用户反馈担心的是"两个名字并排"这一观感，因此把规则扩到任意分隔符，一次收干净。

## 修改

`shared/attribution.ts`：

- 分隔符扩为 `｜ | ／ / ： : （ ( 【 [ 、 · •`，取第一个非空片段。
- `《》` 不算分隔符（节目名），`HowToCook 社区菜谱` 这类空格也不切。
- 通用标签前缀（`账号名`/`作者`/`来源`/`出处`/`署名`/`UP主`）不计入名字，遇到时取下一段，避免把"账号名：王刚"显示成"账号名"。
- 存储的 `author` 原样保留，只改展示。
