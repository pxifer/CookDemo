# main-v72：宽食材归并、目标级一般倾向、对话去除依据

2026-11-14 01:2x 更新既有 CloudBase HTTP 函数成功。

## 1. 食材下拉继续简化

- 按物种归并：猪、牛、羊、鸡、鸭、鹅、鱼、虾、蟹、贝。
- 五花肉、猪大肠、猪肚、猪血、羊里脊、羊通脊、樱桃谷鸭子、仔鸡、自制腊肉等都不再单独出现，统一落到猪肉/羊肉/鸭肉/鸡肉。
- 猪油、猪皮等调料/非主料仍排除；`猪油`不会被归成猪肉。
- 调料“其他”分组保持 v68 的分类。

## 2. 目标级一般饮食倾向（新增）

不依赖“成年人/运动情况”等未确认条件，也能给出逐菜倾向：

- 瘦身/减脂：优先蒸、煮、炖、凉拌、焯；煎、炸标为“建议少选”。
- 增肌：优先蛋白主料（鸡蛋、鸡肉、牛肉、鱼虾、豆腐、瘦肉等）。
- 排序与单菜说明都使用该倾向，并明确写“一般饮食倾向，不是疾病结论”。

这解决“用户有目标 → AI 给食材 → 菜品无法判断”的断链：即使知识条件未确认，也有菜品级的一般倾向可依据。

## 3. 对话不再展示依据/来源

- 系统提示要求不输出“依据：…”“参考：…”“来源：…”或指南名；程序还会删除回复末尾的依据行。
- 目标缺少成年人/运动条件时，要求先问一个关键问题，不得再说“档案完整/无需补充”。
