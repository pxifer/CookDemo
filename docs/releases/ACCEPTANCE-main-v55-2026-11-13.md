# main-v55：图片入口、AI 菜数、用户文案与响应时间

2026-11-13 北京时间 20:36 更新既有 CloudBase HTTP 函数成功。发布代码 `74c74d4`；函数超时保持 60 秒，知识引用与内容版本不变。这是对用户反馈的五项问题的第一轮修复。

## 修复内容

1. **图片识别入口消失**：入口不再依赖“整理信息”后的展开状态；首屏和识别/添加食材后都保持可见（`frontend/src/main.tsx`），并新增 e2e 断言。
2. **AI 模式移除“图鉴搭配示例”**：不再在健康对话下展示图鉴示例列表，避免与 AI 搭配混淆。
3. **面向用户的文案**：移除 RAG、候选、核验、覆盖、模型额度等内部术语；健康结果、失败提示、对话说明改为用户能读懂的表达。
4. **AI 菜数遵守人数/荤素/补买**：AI 选菜按人数参考或用户自定义荤素汤确定总数与各类数量，不再固定 6 道；候选浏览（“更多菜谱”）仍每页 6 道。
5. **响应时间**：AI 候选目录从最多 48 道降到 **12 道**（候选浏览 18 道），摘要限 160 字、单菜理由限 80 字，输出 token 上限随菜数伸缩（最多 1600）；做法仍按原文提供。1 人自动餐提示约 9k 估算 token（原约 21–23k），输出菜数从 6 道降到人数参考值。
