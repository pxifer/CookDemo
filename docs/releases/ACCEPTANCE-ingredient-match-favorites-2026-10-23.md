# 猪肉部位匹配、未知用量与图鉴收藏响应验收

日期：2026-10-23。依据用户对“猪肉”匹配、缺少用量展示和图鉴收藏交互的明确要求；决策见 [D13-05](../product/decision-log.md)。

## 验收行为

- 用户确认的通用“猪肉”可以匹配五花肉、里脊、梅花肉、猪排/排骨、猪蹄/猪肘及猪肉馅主料，菜品可以参与推荐，并满足至少复用一个现有主料的门槛。
- 这只用于猪肉大类召回。具体部位及库存数量仍未核实，不拿通用猪肉克数抵扣五花肉/里脊用量、不报精确缺口。精确同 ID 的单位、形态和计量基准核对继续生效。
- 菜谱用量为空、库存也未录入时，显示“原方未注明用量，无法估算补买量；请核对库存”，状态保持未核实，不补零或伪造补买数。
- 图鉴点击收藏后立即更新当前收藏状态；仅对应菜名/口味按钮在同步期间禁用。其他卡片继续可操作；映射失败时恢复这一个收藏的原状态并显示错误。

## 未覆盖范围

没有把肉类间、植物性食材间、部位反向或数量互换定义为等价。用户录入具体部位而菜谱使用其他部位时仍不推断可互换。此处不构成食材标准词典审核、候选菜谱质量审核或正式发布批准。
