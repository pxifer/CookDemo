# main-v90：食材输入常显、补买清单同单位合并

2026-11-15。只发代码，内容版本不变（仍 `gallery-listed-foods-1000-20261114-v3`）。

## 变更

1. **手动输入不再折叠**：去掉“搜索或直接输入食材”的下拉/折叠标题，输入框常显，仍保留输入权限；提示文字改为“没有想要的？直接输入”。
2. **补买清单合并同一单位**：
   - 同一食材、同一单位的多条缺失项求和，例如两道菜的“鸡蛋 2 个”与“鸡蛋 3 个”合并为“鸡蛋 5个”。
   - 单位不同不合并：`鸡蛋 2个` 与 `鸡蛋 50g` 仍分两条。
   - 范围用量（如“3-4 个”）和无法解析的原文不参与求和，也不重复展示。
   - 原方单条用量的显示保持原样，不改变来源表达。
