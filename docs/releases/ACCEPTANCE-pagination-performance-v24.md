# 分页与响应性能 v24/v25

## 本次改动

- 函数实例缓存只保存按 SHA-256 完整验证过的公开、不可变菜谱及成分发布快照。每次读取和推荐结果发布前仍查询发布行是否可见；撤回、缺失或冷启动内容被篡改仍失败关闭。
- 推荐候选、库存、过敏与忌口结果不跨请求缓存，每个请求继续使用当前输入重新核对。
- `contentContext` 建立食物关系索引，并在同一上下文内复用已展开的成分树，避免重复扫描完整关系表。
- v24 后续复现出分页间歇失败的真正原因：游标使用模块启动时生成的随机 HMAC 密钥，下一页被路由到另一个云函数实例时校验失败。v25 改为从已有稳定会话密钥派生专用游标密钥，各实例结果一致，不新增环境密钥。
- 更新线上回归测试，使限制测试直接核验指定菜谱，不再依赖随机排序后的前六道候选。
- 函数设置沿用 v23：免费 HTTP 函数、Node 24.11、256 MiB、20 秒；账号、会话、公开注册、内容版本与密钥原样保留。
