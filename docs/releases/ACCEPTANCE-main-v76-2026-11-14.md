# main-v76：清除非食材行与句子型调料名

2026-11-14。已发布线上（内容 `gallery-listed-foods-1000-20261114-v3`）。

## 根因

v75 修掉了"用量变成食材名"，但还有两类残留：

1. **基础 341 道的空格切分残留**：原文 `猪肉片 200 g`、`蒜 2 瓣` 被按空格切成三段，`g`、`ml`、`瓣` 成了配料行。这些行在卡片上真实可见（`g / 猪肉片 200 g`），下拉里只是被临时正则挡住。涉及 `辣椒炒肉片`、`蒜薹肉丝`、`磷虾蒸滑蛋`、`大蒜炒茄子`、`奶香南瓜羹`、`冬笋丝瓜汤`。
2. **句子型调料名**：源数据的调料字段本身就是一句话，被整串当成食材：
   `起士能吧你盛豆腐的器皿口铺满`、`淡奶看口味吧`、`喜欢奶油口味就多放点`（焗烤豆腐）、`辣椒按口味放`（辣炒干豆腐）。

## 修正

- `isInvalidFoodName` 增加裸单位判定（`g/kg/ml/l/克/毫升/升/斤/两`）。
- `mergeSourceIngredients` 识别句子型碎片（`吧呢啊嘛呀哦哈`、`铺满/放点/喜欢/按口味/看口味/就多放` 等）并**整段丢弃**。不保留开头词：把"辣椒按口味放"救成"干辣椒"等于替原文指定了形态，而步骤扫描本来就会补上真正的辣椒行。
- `build-recipe-1000.ts` 在生成发布包时统一剔除这些行，并删除因此失去引用的食材；**不修改已审核的 `base-bundle.json` 快照本身**，渲染时才应用同一把尺子。

## 边界

- 341 道的原文、ID、做法与用量未改，只是不再渲染非食材行。
- `迷你冬瓜`、`千张`、`新奥尔良口味腌料` 等真实名称保留；曾一度被句子规则误删的 `迷你冬瓜` 已回归。
- 「淡奶看口味吧」整段丢弃后，焗烤豆腐不再含淡奶——原文本身就是"看口味"的可选建议，不为它编造食材。
