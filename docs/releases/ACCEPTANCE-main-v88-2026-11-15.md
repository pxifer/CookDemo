## 变更

1. **去掉数量控件下方的小字**：“按你选择的荤、素、汤道数凑齐……”与“按现有食材匹配菜谱……”两段说明删除。
2. **荤素汤目标只出现一次**：保留结果区标题下方的“目标 2 荤 · 2 素”，其余位置不再重复数字。
3. **数量为 0 的类别不展示**：目标与缺额都只列非零项，例如“还缺：荤菜 1 道”，不再出现“汤 0 道”。
4. **配齐标题不再重复数字**：`已按 2 荤 2 素 0 汤配齐` → `已按目标配齐`。
5. **删除凑不齐时的底部解释句**：“食材匹配到的菜品不足指定数量……”“现有食材还不足以凑齐指定数量……”两条后端原因移除；操作仍由“允许补买 / 改成不限数量”按钮承担。
6. **保留有意义的提示**：搜索未完成的“还可以再试一次，看看其他搭配。”和完全无结果的通用提示继续保留。
7. 结果条件行不再重复菜数，只保留“按我的饮食要求 / 也可照顾同餐人 · 允许补买 / 不额外补买”。
