# main-v91：手动输入去掉建议下拉；同一食材的未注明用量折叠

2026-11-15。只发代码，内容版本不变（仍 `gallery-listed-foods-1000-20261114-v3`）。

## 变更

1. **手动输入去掉下拉建议**：输入框不再挂 `datalist`，只保留自由输入 + “＋ 添加”；改名未识别食材时的候选建议保留（那是纠错入口，不是添加入口）。
2. **同一食材“有用量 + 没用量”不再显示成两行**：
   - 例如“土豆”与“土豆 1个”合并为 `土豆 1个（另有用量未注明）`。
   - 没有直接吞掉未注明项，避免让用户以为 1 个就够。
3. **不合并的情况保持不变**：
   - 不同食材不合并（`干土豆片` 与 `土豆` 是两种食材）。
   - 不同单位不合并（`鸡蛋 2个` 与 `鸡蛋 50g`）。
   - 范围用量（`3-4 个`）与无法解析的原文不求和。
4. 同食材同单位的求和沿用上一步：`鸡蛋 2个 + 鸡蛋 3个 → 鸡蛋 5个`。

## 判断与难度

- “土豆 / 土豆 1个”应该处理：两行看起来像重复，且用户无法判断哪条算数。处理方式不是简单相加（无用量无法可靠相加），而是已知量求和 + 一句“另有用量未注明”。
- 实现难度低：按食材聚合、区分“有量/无量”，约几十行 + 6 个测试；真正需要产品拍板的是提示文案，已选较克制的表达。
