# main-v74：数量词脏数据彻底过滤

2026-11-14 02:0x 更新既有 CloudBase HTTP 函数成功。

## 根因

菜谱做法/食材原文被切分时，把**数量词**当成了食材名写入菜品配料，于是同一批脏名字既出现在下拉、也会出现在卡片配料里。v73 只按整词精确匹配，漏掉了“几个/几颗/二棵”这类。

## 修正

`isInvalidFoodName` 现在同时覆盖：

- 计数单位补全：颗、棵、株、枝、瓣、枚、双、对、段、节、张、串、斤、两、克、毫升；
- 全角数字（０-９）与范围写法（1-2 个、2～3根）；
- “数量词后没有实义名词”的判断：几个、几颗、二颗、二棵、一到、十几、很多、数颗；
- 保留真实食材：八角、五花肉、海虹、干海带、阿胶等不会被误删（已加回归用例）。

同时把“大骨棒/棒骨/筒骨”归并到猪肉，不再作为独立条目。

## 边界

- 这是**展示层过滤**：卡片与下拉不会再显示这些词；原始菜谱数据未改写。
- 线上 1000 道内容读取仍返回“未就绪”，无法在本地逐条导出完整清单；已用本地 341 道快照 + 规则用例验证。刷新后若仍有类似“三个半、七八片”等变体，把名称发我即可补齐。
