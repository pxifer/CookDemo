| 用户反馈 | 实际修改与边界 |
| --- | --- |
| 图片与菜名不符 | 移除推荐卡和详情按荤／素类别复用图片的路径；只有具体菜谱的 `imageUrl` 才可展示。番茄炒蛋已绑定对应原创图；其他缺图明确留空，不借其他菜的图补位。尚未补齐全部成品图 |
| 空食材却要求添加 | 空清单且主动允许补买时，可以查看默认候选，或按指定荤素汤数量搭配，并列出补买量；已有食材时保持原复用要求。未知食材不能伪装为空清单绕过核验；过敏／忌口／健康门槛保持有效 |
| 全局口味过少 | 从当前数据库已发布菜谱变体生成快捷按钮及“更多”下拉；请求Schema允许口味字符串，服务端再按当前内容校验，未知值拒绝 |
| 单菜口味不真实 | 按该菜数据库变体展示，单味菜只显示口味，多味菜才能选择；选择后重新检查限制与库存。候选鸡蛋羹两份咸鲜做法放入同味参考，清蒸鳜鱼两种实际口味保留下拉 |
| 调料不足 | 本地新版本包含29种调料，分油盐酱醋、葱姜蒜与辣味、香辛料、勾芡与提鲜；调料选项均有数据库食物记录。复合调料成分未知不冒充完整；过敏检查继续保守处理 |
| 图鉴是对话框 | 改为可直接访问和刷新的 `/recipes` 页面，包含菜名搜索、食材／做法／口味／菜品类型四栏筛选、24道分页和页内详情。详情也不使用对话框；不显示来源链接。来源证据仍内部保留 |
| 来源单一与网络图片 | 直接用浏览器核验抖音、B站、小红书原页可访问；既有研究资料并非全来自GitHub。新核查与准入缺口见[来源复核](../../datasets/recipes/sources/multisource-recheck-2026-10-22.md)；没有将仅看标题／评论的视频冒充完整配方入库 |
