# 人数与单道菜用量解耦验收

日期：2026-10-20（Asia/Shanghai）。依据：用户明确“人数只和菜品数量有关，和菜品量无关，所有做法和收藏里不要标记人数，也不被其影响”，追踪 D7-14。

## 行为变化

- 人数只影响自动菜数/荤素汤参考，每道菜始终使用该口味完整标准配方量；不按本餐人数或历史标准份数放缩。
- 单菜库存、整套餐累计、补买差额和营养参考均采用相同固定量。固定自定义菜数时，人数变化不改变单菜资格、整套需求、口味或补买结果。
- 详情去掉“几人份”，改为“菜谱参考用量”和“标准配方整道菜”；步骤删除“按当前人数分装”。收藏列表和收藏详情不显示人数。
- 收藏复查与人数编辑状态、本餐自定义数量解耦，不修改本餐；仍检查当前食材、过敏/忌口、调料/补买和相应健康状态。人数暂留空不阻止打开收藏。
- 工作台用餐人数改称“人用餐”，避免暗示单菜份量会变化。人数表明确只用于菜数参考。
