# 录入与设置界面验收

日期：2026-10-20（Asia/Shanghai）。依据：用户两张截图及本轮逐项要求，决策日志 D7-04～07。范围为本地 React/Fastify 工程的界面和录入交互。

## 完成结果

- 食材单行展示，录入后直接参与推荐，去掉计量基准/生熟下拉、额外确认及待核对提示。用量选填，常用单位下拉默认 g，支持 kg、斤、个、ml、l、把、根、块；空值不补零，约量保留。手动食材建议及追加清单排除调料，调料单独管理。
- 同名不同用量保留原值，用户明确选择旧值或新值；换算一致及重复空值不产生无意义冲突。旧本餐的已知食材在恢复时直接可用；数量冲突保留。
- 过敏和忌口独立录入、确认。默认仅本人，主动勾选才合并同餐人的要求。类别确认展示具体食物范围，未知/冲突限制继续阻断，人数变化不改变限制范围。
- 调料与补买分离。默认一键搭配；开启补买自动显示更多菜谱、补买清单和翻页，关闭后恢复套餐。左栏删除重复健康入口，顶部健康入口保留。
- 保留 UI Demo 总体布局和配色。批量录入后自动收起输入区域；食材清单桌面最多 224px、手机最多 188px，独立滚动；偏好采用紧凑入口与弹窗。八种食材用例中左栏总高小于 860px。手机工作区显示时提供底部操作按钮，通知置于按钮上方。
- 去掉示例/实验室入口、开发预览/构造/草稿等常驻文案，改用用户能理解的提示。常用偏好、收藏和刷新恢复保留。弹窗支持 Escape、关闭后焦点回到触发入口；320/390/768/1440px 无横向溢出。
