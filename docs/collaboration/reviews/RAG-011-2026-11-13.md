# RAG-011 管理审核：第三批 u49-t2 重复追问修复

审核日期：2026-11-13。基线：`main` @ `e67707d`。来源：第三批独立评分回件 u49-t2（用户已说明不知道分型，回复仍逐字重复原问题）。

## 1. 复现

用真实本地知识包与 `researchFoodChat` 复跑原对话：

- 首轮“我有糖尿病，晚餐食材怎么选？”→ 回复“还需确认：糖尿病分型（1型、2型或其他；不清楚可直接说明）。”
- 次轮“我不知道是几型，检查单现在不在身边。先告诉我能提供哪些帮助，不要再问同一个分型问题。”→ 修复前**逐字重复同一句**。

原因是追问归一化只识别“不清楚/不知道”单独成句，没有识别“不知道是几型/不清楚哪种分型”；而重复保护只看 `known` 字段，所以同一问题被再次提出。

## 2. 修复

`backend/src/rag/food-guidance-chat.ts`：

- 糖尿病追问归一化增加“不确定 + 几型/分型/哪种型”的表达，映射为“我不清楚糖尿病分型”。
- 新增“用户无法回答的追问不得重复”规则：若本轮用户明确表示不清楚/不知道/没查/不记得/不在身边，则不再提出同一追问。
- 当某主题仍是 `needs_topic_detail` 且该条件已记录为 unknown 时，回复明确边界：“只保留一般饮食提示，不再重复询问；分型未知时不套用1型/2型的具体指导”，不把未知当已确认。
- 未知状态仍写入会话档案，供后续轮次沿用；不自动猜测分型，也不放宽任何限制。
