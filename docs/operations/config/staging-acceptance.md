## 测试函数配置

以下仅是配置字段说明，示例值不能直接部署。测试站保留原有会话/CSRF/资料加密配置，使用独立测试目标的密钥；候选包不会复制正式配置或密钥。

| 字段 | 要求 |
| --- | --- |
| `APP_STAGE` | `staging` |
| `CLOUDBASE_ENV_ID`、`STAGING_ENV_ID` | 同一个已确认的独立测试环境ID，与正式环境不同 |
| `APP_ORIGIN` | 测试站完整HTTPS origin，无路径和尾斜线 |
| `STAGING_ALLOWED_USER_IDS` | 管理端核对过的测试UID，逗号分隔 |
| `STAGING_RECOVERY_EMAILS` | 对应测试账号的邮箱，逗号分隔，最多20项；按现有API统一小写，不扩展加号别名或其他地址 |
| `PASSWORD_RECOVERY_ENABLED` | 默认`0`；只有需要真实找回联调且名单已配置时设为`1` |
| `PUBLIC_REGISTRATION_ENABLED` | 保持`0`；测试包装器也会拒绝注册 |

名单在后端发信前和解密重置挑战后分别检查。启用找回但邮箱名单为空，启动直接拒绝；移出名单后的旧挑战也不能继续重置。测试站账户登录和资料访问仍要求指定UID；找回入口允许尚未登录的访客验证指定邮箱，不能要求用户先登录才能找回。
