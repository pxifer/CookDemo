# 当前验证边界与剩余事项

本页替代按轮次追加的旧推进清单。历史结果见[验收目录](../releases/)，本次结构整理的结果见[整理报告](../maintenance/reorganization-2026-11-03/README.md)，不把旧版本通过数复制为当前版本通过。

当前仅运行本地必要验证，云端、真实邮件、付费模型和完整灾备演练继续暂停。没有额外 CloudBase 测试环境；Key/邮箱已经配置、历史 5 元预算或上一次维护发布均不授权恢复调用。详见[资源约定](resource-preservation.md)。

| --- | --- |

| 本地验证 | 统一入口包括构建、类型、单元、知识及契约、四组浏览器和六组 PG；缺配置/权限是未运行，不以 PGlite 代替真实 PG |

| 注销 | 已有二次密码确认、撤销标记及后台续作；生产独立持久日志、管理员身份删除适配器未接入；没有可注销真实测试账号，不能删除正式账号 |
| 业务备份/恢复 | 已有加密快照、结构/权限指纹、身份/图片/密钥核对、最新撤销水位及隔离恢复；真实可信撤销头、身份导出与完整恢复仍待受控验证，旧会话不能恢复 |

| 图片识别与疾病 RAG | 图片入口仍是本页预览；研究检索、绑定样例及一般模型选菜不等于图片识别、正式疾病推荐或临床签认 |
| 向量/重排及容量 | 保留结构化/词法基线；先形成独立失败集和性能证据，再决定新增模型或基础设施 |

未来只有取得针对具体目标的授权，才验证专用邮箱/可删除账号、隔离恢复、真实模型质量与发布回滚；不要求为清理目录购买测试环境。模型质量须分别检查真实 ID/配料/完整做法、过敏与已接受排除、库存/补买累计、健康建议条件和不可诊断边界；严重安全错误不得用其他指标抵消，缺样本不算通过。

恢复演练必须覆盖真实身份、资料密钥、最新撤销头、RLS/函数/权限及图片；回滚不得复活已撤回来源或已删除资料。测试错误依实际环境处理，不通过关闭防火墙、改生产密码或切换正式服务补证据。

本地完整检查使用 `scripts/run.ps1 test:local`；普通终端入口 `scripts/verify-in-terminal.ps1`。退出码 0 为完成，1 为失败，2 为阻塞/未完成；新报告写入新时间目录。真实质量与发布细则见[评测协议](../../agent-design/evaluation/protocol.md)、[配置说明](config/staging-acceptance.md)和[历史验收](../releases/ACCEPTANCE-release-execution-2026-10-29.md)。
